# OhMemoJang

> 이전 이름: MEMONOKING. 구조는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 기능 명세와 구현 상태는 [docs/SPEC.md](docs/SPEC.md)에 있습니다.

Windows 10/11용 개인 메모·할 일·일정·위키 작업 공간입니다(Rust + egui/eframe). 메모 하나가 바탕화면의 스티커 창 하나이고, 내 작업실·캘린더·전체메모·나만의 위키에서 같은 메모를 다룹니다. 메모·위키·설정은 자동으로 저장되며, 처음 실행하면 나만의 위키의 ‘사용법’ 탭이 열립니다.

## 내려받기

최신 릴리즈는 [v2.2.1](https://github.com/chobo-mj/OhMemoJang/releases/tag/v2.2.1)입니다.

설치 기본 위치는 `%LOCALAPPDATA%\Programs\OhMemoJang`입니다. 데이터는 `%APPDATA%\OhMemoJang`에 저장되며 프로그램을 제거해도 남습니다. 실행 PC에 Rust·C++ 빌드 도구나 Visual C++ 런타임이 필요하지 않습니다. 배포 파일은 정적 C 런타임 검사와 설치·제거 검사를 통과한 것만 게시합니다. 자세한 내용은 [설치·패키징 안내](packaging/README.md)에 있습니다.

## 소스에서 실행

Rust stable과 Windows C++ 빌드 도구를 설치한 뒤 `cargo run --release --locked`를 실행합니다. 빌드할 때 의존성 다운로드에 인터넷이 필요합니다. 설치된 Windows 글꼴을 쓰고, 없는 글꼴은 기본 글꼴로 표시합니다.

## 주요 기능

- **스티커 메모:** 스티커 → 제목 한 줄 → 색상 상자로 접힙니다(상자는 한 번 클릭하면 펼쳐짐). 메모마다 투명도, 항상 위, 본문 탭, 서식, 표·이미지 붙여넣기, 프로젝트·연결 메모, 알람·일정을 둘 수 있습니다. 더보기와 우클릭 메뉴(정렬 포함)는 스티커 밖 별도 창에 뜹니다.
  - 본문·제목줄 우클릭 메뉴에서 ‘글꼴…’(글꼴·크기·서식·글자색·형광펜, 미리보기), 투명도, ‘닫기 버튼 잠금’(X·Esc·Alt+F4로 닫히지 않고 메뉴로만 닫힘)을 고릅니다.
  - 접기: ‘컬러박스 생략’(제목줄까지만 접기), 컬러박스 크기 정하기, 접힌 메모끼리 경계가 자석처럼 붙는 정렬(기본 12pt).
  - 본문을 마우스로 끌거나 Shift+방향키로 고르면 잘라내기·복사·글자색·형광펜 팝업이 뜹니다. Ctrl+Z로 본문은 그대로 두고 글자색·형광펜만 되돌릴 수 있습니다.
  - 새 메모 색은 한 가지 색 또는 ‘번갈아가며’(새 메모마다 팔레트 색이 차례로 바뀜)로 고릅니다.
  - 메인 창을 고르면 스티커와 접은 메모가 메인 창 바로 뒤에 모입니다(‘항상 위’ 메모는 그대로). Win+D로 바탕화면을 볼 때도 열려 있던 스티커는 보이게 둘 수 있습니다(기본 켬).
- **내 작업실 · 오늘의 할일 · 다음에 할일:** 날짜별 목록, 오른쪽 미리보기에서 바로 편집, 필터(프로젝트·정기 일정·생성일 기준·완료 메모 보기), 찾아 바꾸기. 프로젝트 이름을 바꾸거나 두 프로젝트를 합칠 수 있습니다. 조절한 목록·미리보기 너비는 다시 켜도 유지됩니다.
- **캘린더:** 작성일·일정·알람 기준, 여러 날 일정은 색띠 하나, 한 달·1주·2주 보기, 완료 일정 숨기기·취소선, 테마(기본·종이·세이지·나이트). 일정 막대를 다른 날짜로 끌어 옮깁니다(여러 날 일정은 길이 유지). 한국 공휴일(음력·대체공휴일 포함)을 표시하고, 매달 21일이 있는 주의 금요일을 파란색으로 표시합니다. 월 보기의 지난달·다음 달 날짜에서도 메모·일정을 추가합니다. 근무자 보기 버튼은 자리만 있습니다.
- **캘린더 분리창:** 최소화하면 이동·크기 조절·색 변경이 되는 달력 상자로 접히고, 스탠딩 캘린더로 바탕화면에 고정할 수 있습니다. 우클릭으로 보기 단위를 바꿉니다.
  - 스티커를 날짜로 끌어 놓으면 일정, Shift를 누른 채 놓으면 ‘이날까지 할일’이 됩니다. 날짜를 끌면 기간 일정을 만듭니다.
  - ‘스탠딩 상태에서 기능 활성화하기’(기본 끔)를 켜면 바탕화면의 캘린더에서도 새 메모·기간 일정·끌어 놓기·막대 클릭·일정 막대 옮기기를 쓸 수 있습니다(기능별 선택).
- **클립보드 히스토리:** 복사한 글·표·이미지를 모아 두고, 누르면 다시 복사합니다. 같은 내용은 한 번만 쌓이고 맨 위로 올라옵니다(기본 켬).
- **나만의 위키:** 탭별 폴더 트리, 미분류 목록, 두 영역 나란히 보기, 트리 우클릭 새 노트, 끌어서 분류합니다.
- **알람:** 시각이 되면 소리와 함께 오른쪽 아래에 알림 창이 뜹니다(열기·5분 뒤·확인). 꺼져 있던 동안 지난 알람도 알려 줍니다.
- **튜토리얼:** 처음 실행하면 19단계로 스티커·접기·캘린더·분리창 끌어 놓기·클립보드 히스토리·스탠딩 캘린더를 연습합니다. 설정 › 정보 › ‘튜토리얼 다시 하기’로 다시 할 수 있습니다.
- **설정:** 라이트·다크 모드 1·다크 모드 2, 첫 화면, 메뉴 숨기기, 새 스티커 크기, 닫은 스티커를 다시 열 위치(이전 위치·오른쪽·왼쪽·화면 중앙), 매일 오늘 메모 자동 띄우기(05:00 기준), 정렬 모니터, Windows 시작 시 자동 실행(기본 켬, 트레이에서 시작, 스티커·스탠딩 캘린더 복원), 표 붙여넣기 양식(표 / 텍스트), 휴지통 보관 기간, 잠금 메모 자동 잠금, 백업·복원, 전역 단축키(기본 Ctrl+Alt+N 빠른 메모·새 스티커, Ctrl+Alt+C 캘린더 분리창, Ctrl+Alt+S 새 스티커).

## 현재 한계

- 잠금 메모의 비밀번호는 해시로만 저장하지만, 본문은 암호화하지 않습니다.
- 근무자 보기(엑셀 연동), Windows 알림 센터 토스트는 후속입니다.
- 공휴일은 프로그램 안에서 계산합니다. 정부가 새로 정하는 임시공휴일·보궐선거일은 2025년까지 알려진 것만 표시합니다.
- 스티커 창마다 그래픽 드라이버 메모리를 씁니다. 외장 그래픽 카드가 있는 노트북에서는 창 하나에 약 50 MB입니다.
- 이미지 64 MB/8192×8192, HTML 10 MB 반입 제한이 있습니다. 보안 락이 걸린 PDF/PPT/Excel을 읽거나 잠금을 우회하지 않습니다.
- 설치파일은 코드 서명되지 않았습니다.
