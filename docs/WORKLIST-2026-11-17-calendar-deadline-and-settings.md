# 캘린더·마감 업무·설정 개선 작업 목록

작성: 2026-11-17. 구현 전에 요청 범위와 기본값을 정리한다.

## 구현 항목
- [x] 왼쪽 메뉴 너비 드래그 조절·저장. 좁으면 아이콘만 표시하고 배너는 프로그램 아이콘 그림으로 표시.
- [x] 이날까지 업무 데이터와 저장 호환성. 일정 설정에서 달력과 반복 사이에 체크박스를 배치하고 종료 날짜를 마감일로 사용.
- [x] 캘린더(메인·분리창)에 메모·스티커 드롭 지원. 일반 드롭은 당일 일정, 옵션 ON이면 당일 일정/이날까지 업무 선택 팝업.
- [x] 일반 설정에 ‘메모 끌어 놓기 시 이날까지 업무 선택창 띄우기’, 기본 OFF.
- [x] Shift+날짜 드롭은 옵션과 관계없이 이날까지 업무로 즉시 지정하고 팝업 생략. 캘린더 및 선택일 할일 리스트에 적용.
- [x] 이날까지 업무의 캘린더 제목 앞에 깃발 표시. 제목만 보이는 1번 접힘 스티커에 [D-1] 등의 D-day 표시.
- [x] 매일 오늘 메모 자동 띄우기 ON이면 미완료 이날까지 업무도 항상 표시.
- [x] 내 작업실의 캘린더 우측 선택일 일정 아래에 이날까지 업무 목록. 제목 앞 깃발·D-day 표시.
- [x] 선택일 날짜 제목 확대·굵게, 일정 시간순 정렬.
- [x] 선택일 목록에 일반 드롭은 당일 일정, Shift 드롭은 이날까지 업무. 이 목록에서는 선택 팝업 없음.
- [x] 선택일·오늘 할일·다음 할일 목록에서 메모를 빈 공간 또는 창 밖으로 빼내면 일정 제거. 다른 날짜·유효 대상에 드롭하는 동작과 구별.
- [x] 일정 반복에 매년 추가 및 날짜 경계 검증.
- [x] 새 스티커 메모 크기 설정을 일반에서 메모창 메뉴 최상단으로 이동.
- [x] 메모창 기본 글꼴 선택을 드롭다운으로 변경.
- [x] 일반 설정 ‘스티커 메모 체크완료 시 스티커 닫기’ 기본 ON.
- [x] 위 옵션 ON일 때 ‘완료메모 발생 시 스티커 재정렬’ 표시, 기본 OFF. 완료된 스티커를 닫고 남은 스티커를 기존 위치 순서를 유지해 모니터 오른쪽에 1번 접힘 상태로 재정렬.
- [x] 단축키 설정 전역단축키 아래 ‘메모 본문영역 서식 단축키’ 구역: 취소선·굵게·기울임·밑줄·체크박스·날짜·시간·첫줄 프로젝트 지정.
- [x] 이날까지 업무 Shift 드래그 안내 추가. Ctrl+P, Esc 두 번, Ctrl+F, Ctrl+H 기존 용도 유지.
- [x] 클립보드 히스토리 ‘메모장 복사 수집 안 하기’ 기본 ON.
- [x] 클립보드 자동정리 주기 UI 제거, 매일 로컬 정오 12시에 실행. 꺼져 있었다면 다음 시작 시 누락된 정리 실행·실행일 저장.
- [x] 클립보드 개수 제한 기본 OFF, 기존 사용자 설정은 보존.
- [x] 본문 이미지가 너비 맞춤 이외 모드에서는 보이는 본문 폭보다 크게 확대될 수 있게 수정.

## 구현 원칙과 검증
- 기존 저장 파일에 없는 필드는 기본값으로 읽으며 사용자 데이터는 보존한다.
- 매 프레임 전체 데이터 해시·정렬·디스크 기록을 새로 추가하지 않는다. 변경 시점과 날짜 전환 시점에 필요한 작업만 수행한다.
- [x] 날짜/마감/반복/정오 정리/완료 후 처리 회귀 테스트.
- [x] cargo fmt, 전체 테스트, Clippy 검사.
- [x] 격리 데이터 실제 창에서 메뉴 리사이즈·캘린더 드래그·설정·스티커 완료·이미지 확대 검증. Shift 조합은 입력 이벤트 회귀 테스트로 검증(아래 범위 참고).
- 종료 지연 추적은 이번 작업에 포함하지 않는다.


## 완료 및 실제 창 검증 기록
- 메뉴 경계 드래그로 너비 변경, 아이콘 전용 모드와 프로그램 아이콘, 검색 아이콘을 확인했다. 너비는 드래그 완료 때만 설정에 기록한다.
- 일반 메모 → 메인 캘린더 기본 당일 일정 추가, 선택 옵션 ON일 때 팝업과 이날까지 업무 추가를 확인했다.
- 선택일 목록으로 드롭했을 때 팝업 없이 일정 추가, 목록 빈 공간으로 빼낼 때 일정 제거, 다음 할일에서 빼낸 메모가 일정 없는 메모에 남는 것을 확인했다.
- 빠른 스티커 드래그가 한 프레임에 끝나도 드롭을 처리한다. 메인 캘린더 및 분리 캘린더에서 팝업 표시와 실제 날짜 저장을 확인했다.
- 두 캘린더가 겹칠 때 뒤쪽 날짜가 선택되던 오류를 수정했다. 화면 좌표 후보가 겹치면 드롭 시점에만 Windows 창 순서를 확인한다. 수정 후 분리창의 11월 21일 선택 및 깃발 표시를 확인했다.
- 일정 설정의 이날까지 업무 체크박스, 종료 날짜 변경, 매년 반복을 확인했다. 제목 접힘 상태에서 D-day 표시, 완료 체크로 닫기와 다른 스티커의 오른쪽 접힘 재정렬을 확인했다.
- 일반 옵션의 초기값, 메모창 최상단 크기 설정, 글꼴 드롭다운, 전역 단축키 아래 본문 서식 단축키 구역을 확인했다.
- 800px 이미지가 360px 스티커 본문보다 크게 표시되고 가로 스크롤로 반대편을 볼 수 있는 것을 확인했다. 크기 메뉴가 창 밖으로 잘리는 문제도 수정했으며 25%/50%/75%/100%/너비 맞춤/복사/삭제가 모두 보이고 25% 변경이 적용됨을 확인했다.
- 자체 복사가 Windows에 소유 창을 남기지 않는 경우를 보완했다. 앱 복사 경로와 egui 복사 명령을 공통 처리하고 클립보드 시퀀스를 기록한다. 수집 스레드는 복사와 경쟁할 때 대기 잠금 대신 재시도하며, 앱 복사 제외 옵션 OFF에서는 정상 수집한다.

## 검사 및 검증 범위
- 자동 회귀 테스트: 마감일/완료 상태/일정 제거/매년 윤년 경계/설정 저장 호환성/정오 정리와 다음 시작 시 보충/스티커 재정렬/빠른 드래그/Shift 조합/이미지 원본 크기.
- Windows 실제 클립보드 별도 테스트: 기본 제외 → 옵션 OFF 수집 → 다시 ON 제외. egui 복사 명령 처리도 포함.
- Shift를 누른 채 실제 마우스 드래그와 창 경계를 넘어가는 긴 드래그는 현재 UI 도구가 지원하지 않아 직접 조작 검증하지 못했다. 해당 분기들은 입력 이벤트 및 화면 좌표 회귀 테스트로 검증했다.
- 다중 모니터 및 서로 다른 DPI 배율 조합은 이번 환경에서 검증하지 않았다.
- 실제 사용자 메모 대신 `target/qa-feature-data`의 격리 데이터로 창 검증했다.
- 목록 정렬은 기존 변경 기반 캐시를 사용한다. 매 프레임 전체 데이터 정렬이나 디스크 저장을 추가하지 않았으며 창 앞뒤 순서 조회도 드롭 때만 수행한다.
- 종료 지연 추적은 요청대로 수행하지 않았다.
