# 메모 목록 표: 왼쪽 경계 드래그로 모든 열 너비 조절, 열 선택 확대

대상: 내 작업실 자세히 보기·전체 메모 보기(`catalog_split_list`)와 휴지통의 메모 목록 표(`src/catalog.rs`).

## 너비 조절
- 조절 손잡이를 각 열의 **왼쪽 경계**로 옮겼다. 모든 열(표시/복원, 완료, 제목, 내용, 알람, 생성일, 일정,
  완료일, 위키, 프로젝트, 중요, 삭제)에서 보이는 첫 열을 뺀 각 열의 왼쪽 가장자리를 끌면 된다. 더블클릭하면
  그 열이 기본 너비로 돌아간다.
- 동작 규칙(`drag_border`): 내용 뒤쪽 열(알람~삭제)은 그 열의 왼쪽 가장자리를 왼쪽으로 끌면 그 열이 넓어진다
  (가장자리가 마우스를 따라온다). 내용 앞쪽(표시·완료·제목)은 경계의 왼쪽 열이 바뀐다. 즉 완료 앞 경계는
  표시를, 제목 앞 경계는 완료를, 내용 앞 경계는 제목을 조절한다. 내용은 다른 열이 남긴 폭을 차지하고,
  제목은 사용자가 너비를 정하기 전까지 남은 폭의 일부를 가진다. 내용 너비는 제목·뒤쪽 열 경계를 끌어 조절한다.
- 열이 많아 표가 목록 폭보다 넓어지면 표가 넓어져 가로 스크롤이 생긴다(`table_total`). 내용 최소 60,
  제목 80~800, 나머지 24~300.

## 열 보이기/숨기기
- 열 제목줄 우클릭(그리고 열 표시 목록)에서 완료, 알람, 생성일, 일정에 더해 **완료일, 위키, 프로젝트, 중요,
  삭제**를 고를 수 있다. 표시·제목·내용은 항상 보인다.
- 새 열은 처음에는 숨겨져 있다(`ColumnShown` 기본값). 완료일은 완료한 날짜·시각(반복 일정은 그 날의 완료),
  위키는 위키 보관 여부, 프로젝트는 프로젝트 이름, 중요는 ★를 보여 준다(표시 전용).
- 삭제 열은 마지막 열로 유지된다(내부 번호 7 → 11).

## 검증
- 새·수정 테스트: 새 열 기본 숨김과 선택 가능한 열 목록, 왼쪽 경계 드래그 규칙과 내용의 나머지 차지, 열이 많을 때
  표 확장, 열 우클릭 메뉴의 항목, 새 열의 값 표시, **실제 마우스 이벤트로 일정 열의 왼쪽 경계를 끌어 너비 증가**.
- fmt, clippy(`-D warnings`), 테스트 256개 통과.
- 열 너비·표시 설정은 이전과 같이 실행 중에만 유지된다(저장하지 않음). 실제 화면은 직접 확인하지 못했다.
