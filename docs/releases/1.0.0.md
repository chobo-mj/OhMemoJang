# OhMemoJang 1.0.0

Windows 10/11 x64용 정식 릴리즈입니다.

## 새 튜토리얼: 실제 화면에서 따라 하기
- 처음 실행하면 튜토리얼을 시작할지 물어봐요. 설명하는 부분만 밝게 남기고 나머지는 어둡게 가려요. 설명창이 그 옆을 따라다니며 짧은 시연 애니메이션을 보여 줘요.
- 직접 해내면 저절로 다음 단계로 넘어가요. 다루는 기능은 #프로젝트 분류, 제목 자동 입력, 여러 단계 목록과 Enter로 위 단계 올라가기, 물결(~~)로 취소선 긋기, []로 체크박스 만들기, 달력 아이콘을 끌어 일정 만들기, Shift로 끌어 이날까지 할 일 만들기, 스티커를 오른쪽에 제목만 보이게 정렬하기, 내 작업실 프로젝트 필터, 완료 체크 후 업무일지에서 확인하기, 캘린더 분리하기, 스탠딩 캘린더예요.
- 언제든 건너뛸 수 있어요. 끝나거나 건너뛰면 연습용 메모와 일정을 모두 지우고 깨끗하게 시작할지, 남겨 둘지 골라요.
- 설정 › 정보의 ‘튜토리얼 다시 하기’로 다시 해 볼 수 있어요.

## 사용법(나만의 위키 › 사용법) 새로 쓰기
- 최신 기능에 맞춰 14쪽을 다시 썼고 스크린샷도 새로 찍었어요. 이미 쓰던 사용법 쪽은 자동으로 새 내용으로 바뀌어요. 직접 추가한 메모는 그대로 둬요.
- 스탠딩 캘린더 쪽에 ‘Windows 11 24H2에서는 동작하지 않아요’ 안내를 넣었어요.

## 그 밖에
- 설정 › 정보에 만든 사람과 안내 문구를 넣었어요.
- 지운 위키 탭이 프로그램을 다시 켜면 되살아나던 문제를 고쳤어요.
- 0.6.4의 성능 개선(같은 화면 다시 그리지 않기, 유휴 CPU 0, 찾아 바꾸기 캐시, 사용하지 않는 이미지 정리)이 그대로 들어 있어요.

자동 테스트 281개가 통과했어요. 튜토리얼 단계는 이 PC에서 직접 눌러 보며 확인했어요. Windows 11 24H2와 다중 모니터 환경에서는 확인하지 못했어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
