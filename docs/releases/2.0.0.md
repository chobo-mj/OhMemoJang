# OhMemoJang 2.0.0

Windows 10/11 x64용 정식 릴리즈입니다. 사용성을 크게 손봤어요.

**알람**
- 반복 알람: 매일 · 평일 · 매주 · 매월.
- 미리 알림: 5분 전 ~ 하루 전에 한 번 더 알려 줘요.
- 한 메모에 알람을 여러 개 둘 수 있어요.
- Windows 알림이 꺼져 있으면 프로그램 팝업으로 대신 알려 줘요.
- 프로그램이 꺼져 있을 때 누른 알림 버튼(열기 · 5분 뒤 · 확인)도 처리해요.

**메모**
- 글자 색과 형광펜.
- 본문 우클릭으로 일정 · 알람 · 스티커 정렬 메뉴를 바로 열어요.
- 체크박스가 있으면 목록과 캘린더에 진행률(2/5)이 보여요.
- 스티커 위쪽 빈 곳을 끌어 캘린더 날짜에 놓아도 일정이 돼요.

**캘린더**
- 날짜 칸을 끌어 여러 날 일정을 한 번에 만들어요.
- 음력 매달 1일을 날짜 칸 오른쪽 위에 흐리게 보여 줘요.
- 내 휴일: 창립기념일 · 휴가처럼 나만 쉬는 날을 넣으면 빨간 날로 보여요.
- Windows 11 24H2 이후에서는 스탠딩 버튼 옆에 ‘지원 안 됨’이 작게 보여요.

**그 밖에**
- 하루 한 번 자동 백업(최근 7개).
- 어디서나 검색 창을 여는 단축키 Ctrl+Alt+F.
- 첫 실행 때 데이터 폴더를 묻지 않고, 튜토리얼에서 위치를 알려 줘요.
- 위키의 사용법 문서를 새 기능에 맞게 고쳤어요.

자동 테스트 296개가 통과했어요. 이번 기능들의 실제 화면 확인은 하지 못했어요. 이상한 점이 있으면 알려 주세요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다. 2.0.0에서 저장한 글자 색 · 반복 알람은 이전 버전으로 되돌리면 사라집니다.
