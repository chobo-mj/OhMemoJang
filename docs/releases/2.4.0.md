# OhMemoJang 2.4.0

Windows 10/11 x64용 릴리즈입니다.

## 변경 사항

- 메인 작업 공간을 새롭게 정리하고 **라이트 2**와 **라이트 3** 디자인을 추가했습니다. 기존 밝은 디자인은 라이트 1에서 사용할 수 있습니다.
- 기존 **다크 모드 1**과 **다크 모드 2**를 함께 제공합니다. 설정 → 메인창 → 테마에서 다섯 가지 중 선택할 수 있습니다.
- 라이트 2는 기존 캘린더 격자를 유지하고, 라이트 3은 둥근 날짜 타일과 카드형 탐색을 사용합니다. 모든 라이트 테마에 기존 프로그램 배너를 표시합니다.
- 테마 설정이 없는 경우 라이트 2로 시작하며, 선택한 테마는 다음 실행에도 유지됩니다. 저장 파일에 남아 있는 기존 다크 모드 설정도 읽습니다.
- 메모·일정·위키·클립보드의 기존 데이터와 동작은 유지합니다.

## 다운로드

- **Setup.exe**: 현재 사용자 계정에 설치합니다.
- **Portable.zip**: 압축을 풀어 실행합니다.
- **SHA256SUMS.txt**: 다운로드 파일의 해시를 확인할 수 있습니다.

메모와 설정은 `%APPDATA%\OhMemoJang`에 저장되며 프로그램을 제거해도 남습니다. 설치 파일과 포터블 프로그램은 Windows 10/11 x64에서 사용합니다.
