# OhMemoJang 1.0.2

Windows 10/11 x64용 정식 릴리즈입니다.

- **알람이 제때 울리지 않던 문제 수정** (0.6.4~1.0.1): 아무 입력 없이 두면 알람 시각이 지나도 알람이 뜨지 않았어요. 이제 제시간에 떠요.
- **공휴일 자동 표시**: 캘린더에 공휴일이 빨간 날짜와 이름으로 나와요. 인터넷 없이 프로그램이 직접 계산해요.
  - 설날·추석·부처님오신날은 음력을 계산해서 정해요.
  - 대체공휴일, 선거일, 2026년부터 공휴일이 된 노동절·제헌절도 반영했어요.
  - 갑자기 정해지는 임시공휴일은 미리 알 수 없어요.
- **Windows 알림 센터 알림**: 알람이 Windows 알림으로 뜨고, 알림에서 바로 열기 · 5분 뒤 · 확인을 고를 수 있어요. 놓친 알림은 알림 센터에 남아요.
  - 설정 › 알람에서 예전 팝업 방식으로 바꿀 수 있어요.
  - Windows 알림을 쓰려고 시작 메뉴에 OhMemoJang 바로가기를 만들거나, 설치본의 바로가기를 그대로 써요.

자동 테스트 288개가 통과했어요. 이 PC에서 직접 확인한 것:
- 알람이 Windows 알림으로 뜨고, 알림의 ‘5분 뒤’ 버튼이 동작해요.
- 캘린더에 공휴일이 표시돼요.

설치본의 바로가기와 집중 모드(방해 금지)에서의 동작은 확인하지 못했어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
