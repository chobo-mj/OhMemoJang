# OhMemoJang 0.6.3

Windows 10/11 x64용 정식 릴리즈입니다.

- 나만의 위키: 탭을 삭제하면 탭 안의 메모까지 휴지통으로 이동합니다. 휴지통에는 `탭이름/`으로 묶여 보이고, 눌러서 펼쳐 메모를 확인합니다. 우클릭 ‘복구’ 또는 왼쪽 복원 버튼으로 탭과 메모 전체를, 펼친 메모 하나만 복구하면 탭이 다시 생기고 그 메모만 돌아옵니다. 탭 안 메모 하나만 지우면 `탭이름/메모제목`으로 보이고, 탭을 지우면 한 묶음으로 합쳐집니다.
- 나만의 위키 우클릭 메뉴: 메모(새 폴더·새 위키 메모·위키 해제·메모 삭제), 폴더(새 폴더·새 하위 폴더·폴더 삭제·폴더·메모 삭제) 추가.
- 전체메모 → 폴더보기: 폴더 우클릭에 ‘폴더 삭제 · 메모 삭제’ 추가. 폴더와 하위 메모가 `폴더/` 묶음으로 휴지통에 갑니다.
- 사이드바: 접기 버튼을 ‘빠른 메모’ 줄 오른쪽 끝으로 이동, 배너 확대, 아이콘만 보이는 좁은 상태에서 아이콘 확대, 프로젝트는 ▶ 버튼의 선택 팝업으로 표시.
- 설정: 메모 창 ‘새 메모’ 구역(모니터 선택·오른쪽 정렬·창으로 크기 설정), 단축키 영역 구분, 설정을 메인 창 안에 표시.
- 메모 목록 표: 열 왼쪽 경계로 모든 열 너비 조절, 완료일·위키·프로젝트·중요·삭제 열 선택.
- 캘린더 분리창: 닫기 버튼은 창 닫기(최소화 버튼만 컬러박스), 가로 배치·스탠딩 아이콘 확대.

자동 테스트 267개가 통과했습니다. 화면 모양(사이드바, 휴지통 묶음, 우클릭 메뉴)은 직접 눈으로 확인하지 못했습니다.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
