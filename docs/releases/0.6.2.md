# OhMemoJang 0.6.2

Windows 10/11 x64용 정식 릴리즈입니다.

- 스티커 메모를 압정 상태로 여러 개 띄웠을 때, 한쪽에서 편집하다 다른 쪽으로 넘어가 이미지를 붙여넣으면 두 메모에 모두 붙던 문제 수정. 키보드 포커스가 있는 창에만 붙습니다.
- Windows 11 24H2 이후에서 스탠딩 캘린더 버튼을 누르면 캘린더가 사라지던 문제 수정. 바탕화면 구조가 바뀐 환경에서는 캘린더를 바탕화면 바로 위의 창으로 고정합니다(아이콘 아래가 아니라 위에 놓이며 작업 표시줄에는 나타나지 않습니다).
- 스탠딩 캘린더 해제 버튼이 고정 상태에서 일반 클릭으로 동작하지 않던 문제와 바탕화면 클릭 감지 위치 문제 수정.
- 트레이 아이콘의 종료를 순차 정리(트레이 아이콘·단축키·클립보드 기록·저장)로 바꾸고, 멈춘 경우 강제 종료하는 감시 추가. 트레이 아이콘이 남던 문제 개선.
- 본문 레이아웃 계산 최적화와 표가 있는 스티커를 최대 크기로 키울 때의 렉 완화.

자동 테스트 242개가 통과했습니다. 스티커 붙여넣기 수정은 창 두 개를 합성 입력으로 흉내 낸 테스트로 확인했고, 24H2 스탠딩 캘린더 수정은 24H2 PC에서 화면으로 직접 확인하지 못했습니다(Win+D 후 동작 포함).

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
