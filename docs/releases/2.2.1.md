# OhMemoJang 2.2.1

Windows 10/11 x64용 릴리즈입니다.

- 메인 창에서 조절한 구역과 열 너비를 앱 재실행 후에도 복원합니다. 사이드바, 내 작업실의 메모 목록·캘린더 경계, 캘린더의 날짜 목록 경계, 오늘·다음에 할 일의 미리보기, 전체메모의 열과 미리보기, 나만의 위키의 트리와 상세 창을 포함합니다.
- 튜토리얼에서 여는 연습 스티커는 새 메모 정렬과 다시 열기 위치 설정에 관계없이 메인 창이 있는 모니터의 중앙에 나타납니다. 정렬 연습의 스티커 세 장은 중앙 부근에 조금씩 어긋나게 배치합니다.

설치 파일은 현재 사용자에게 설치합니다. 포터블 ZIP은 압축을 푼 뒤 OhMemoJang.exe를 실행하면 됩니다. 두 파일의 SHA-256은 SHA256SUMS.txt에서 확인할 수 있습니다.

## 수동 확인

- 내 작업실 캘린더를 두 배치에서 각각 다른 너비로 조절하고, 오늘·다음에 할 일 미리보기, 전체메모의 열과 미리보기, 위키의 경계도 끌어 조절하세요. 트레이에서 앱을 종료하고 다시 실행해 각 화면의 조정값을 확인하세요.
- 설정에서 ‘새 메모 오른쪽 정렬하기’를 켠 채 튜토리얼을 다시 시작하세요. 연습 스티커가 중앙에 열리고, 정렬 연습의 스티커 세 장을 각각 선택할 수 있는지 확인하세요.
