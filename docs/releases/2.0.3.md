# OhMemoJang 2.0.3

Windows 10/11 x64용 정식 릴리즈입니다. 캘린더에서 만든 빈 메모가 남지 않게 했고, 캘린더 메모 우클릭 메뉴를 넣었어요. 창이 여러 개 떠 있을 때 마우스를 움직이며 쓰는 CPU도 줄였어요.

**캘린더 · 일정**
- 아무것도 쓰지 않고 닫은 새 메모는 바로 지워져요. 캘린더와 메모 목록에서 사라지고 휴지통에도 남지 않아요.
  - 대상: 내 작업실 ‘+ 새 일정’, 캘린더 일정 목록의 ‘+ 이 날짜에 스티커’, 날짜 칸의 + 버튼, 날짜를 끌어 만든 기간 일정.
  - 빈 새 메모를 연 채로 프로그램을 끝내도 지워져요.
  - 한 번이라도 내용을 쓰고 닫은 메모는 그대로 남아요.
- 캘린더의 메모를 우클릭하면 스티커로 열기 · 편집창 열기 · 일정 제외 · 메모 삭제가 나와요.
  - ‘일정 제외’는 메모는 그대로 두고 일정만 빼요. 메모는 ‘일정 없는 메모’로 옮겨져요.
  - ‘메모 삭제 · 휴지통’은 휴지통으로 보내요. 휴지통에서 되살릴 수 있어요.
  - 캘린더 분리창에서 메모를 우클릭하면 메모 메뉴만 열려요. 빈 곳을 우클릭하면 전처럼 보기 단위 메뉴가 열려요.

**우클릭 메뉴 · 스티커**
- 본문 메뉴의 잘라내기 · 복사 · 붙여넣기에 단축키가 보이고, ‘모두 선택’(Ctrl+A)이 생겼어요.
- 본문 속 웹 주소를 우클릭하면 메뉴 맨 위에 ‘링크 열기’와 ‘링크 주소 복사’가 나와요.
- 표 칸 메뉴의 순서를 본문 메뉴와 맞추고 단축키를 표시했어요.
- 스티커 아래 안내 문구(예: ‘되돌릴 내용이 없습니다’)는 5초 뒤 저절로 사라져요. 이미지 복사의 성공 · 실패도 알려 줘요.

**설정**
- 일반에는 자동 실행 · 첫 화면 · 메뉴 숨기기 · 휴지통 보관 기간 · 자동 잠금만 남겼어요.
- 스티커 동작(작업표시줄 표시, 체크완료 시 닫기 · 재정렬, 정렬 모니터, 매일 오늘 메모, 툴바 자동 숨기기)은 메모창으로 옮겼어요.
- ‘메모 끌어 놓기 시 이날까지 업무 선택창 띄우기’는 캘린더로 옮겼어요.

**성능**
- 창마다 아이콘을 매번 다시 풀던 문제를 고쳤어요. 창이 많을 때 한 번 그리는 시간이 크게 줄었어요.
- 마우스와 먼 스티커, 스티커 뒤에 가려진 메인 창은 마우스만 움직일 때 다시 그리지 않아요. 측정한 PC에서 마우스를 움직일 때 쓰는 CPU가 약 35~40% 줄었어요.
- 열린 메모의 본문을 매 프레임 복사하던 곳 두 군데를 없앴어요.

**그 밖에**
- 사용법 페이지를 새 내용으로 고쳤어요. 업데이트 후 처음 켜면 바뀌어요.

**확인 못 한 것**
- 배율이 다른 모니터를 함께 쓸 때 스티커 · 메인 창 다시 그리기 판정.
- 그래픽 카드가 하나뿐인 PC에서의 CPU 감소 정도. PC마다 다를 수 있어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
