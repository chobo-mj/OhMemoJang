# OhMemoJang 2.1.2

Windows 10/11 x64용 릴리즈입니다.

- 설정 › 캘린더 › 스탠딩 캘린더에서 ‘일정 막대를 끌어 날짜 옮기기’를 선택할 수 있습니다. 여러 날 일정은 길이를 유지한 채 이동합니다.
- 분리 버튼을 다시 누르면 이미 열린 캘린더 분리창을 앞으로 가져옵니다. 내 작업실의 날짜 범위 끌기와 메모 목록 너비 조절을 개선했습니다.
- 설정 › 메모창에서 닫힌 스티커를 다시 열 위치를 고를 수 있습니다. 이전 위치가 기본이며, 오른쪽 정렬·왼쪽 정렬·화면 중앙도 지원합니다.
- 메인 창을 선택하면 일반 스티커와 접은 메모가 메인 창 바로 뒤에 모입니다. ‘항상 위’로 고정한 메모는 고정을 유지합니다.
- ‘Win+D로 바탕화면을 볼 때 스티커 표시 유지’를 추가했습니다. 기본으로 켜져 있으며, 바탕화면을 보기 전에 열려 있던 스티커에 적용됩니다.
- 나만의 위키에서 Enter로 탭 이름 편집을 마칠 수 있습니다. 프로젝트 관리에서 이름을 바꾸고, 기존 이름을 입력하면 두 프로젝트의 연결 메모를 하나로 합칠 수 있습니다.
- Windows 작업표시줄에 사용하는 앱 ID를 시작 단계에서 적용하고, 스탠딩 해제 후 캘린더가 있던 바탕화면 영역을 다시 그리도록 수정했습니다.

설치 파일에는 현재 사용자용 설치와 제거 기능이 있습니다. 포터블 ZIP은 압축을 푼 뒤 OhMemoJang.exe를 실행하면 됩니다. 두 배포 파일의 SHA-256은 SHA256SUMS.txt에서 확인할 수 있습니다.
