# OhMemoJang 2.2.3

Windows 10/11 x64용 릴리즈입니다.

- 스티커나 선택일 목록의 일정을 날짜 칸 위로 끌면 컬러바가 포인터를 따라오고, 놓을 날짜 칸은 따로 강조됩니다.
- 날짜 칸의 컬러바를 프로그램 창 밖에 놓으면 일정이 해제되고 메모는 유지됩니다.
- 오른쪽 ‘이날까지 업무’ 영역에 스티커를 놓아도 일정이 바뀌지 않습니다.

## 수동 검증

- 메인·분리·스탠딩 캘린더에서 펼친 스티커, 접힌 제목줄, 컬러박스를 날짜 칸 사이로 끌어보세요. 스탠딩 캘린더에서는 스티커 끌어 놓기 옵션을 켜고 확인하세요.
- 선택일 목록에서 일정 행을 날짜 칸으로 끌어 컬러바와 날짜 칸 강조를 확인하세요.
- 기존 컬러바를 앱 창 밖에 놓아 일정만 사라지는지 확인하세요. 앱 창 안의 일반 빈 공간과 ‘이날까지 업무’에 놓을 때도 확인하세요.
