# OhMemoJang 2.1.0

Windows 10/11 x64용 정식 릴리즈입니다. 자동 실행과 스탠딩 캘린더를 다시 손봤고, 흰 창이 남던 그리기 문제, 표 붙여넣기, 한자·기호 입력을 고쳤어요.

**시작 · 실행**
- ‘Windows 시작 시 자동 실행’이 기본으로 켜져요. 이전 버전을 쓰던 분도 업데이트 후 한 번 켜져요.
  - 로그인하면 트레이 아이콘과 시작 알림만 보여요(누르면 메인 창). 꺼내 둔 스티커와 스탠딩 캘린더는 끄기 전 모습 그대로 떠요.
  - 압축 파일 안에서 바로 실행하면 자동 실행을 등록하지 않고 알려 줘요. Windows 설정에서 시작 앱이 꺼져 있으면 설정 › 일반에 경고가 보여요.
  - 실행 기록(`logs\start.log`)과 비정상 종료 기록(`logs\crash.log`)을 남겨요.
- 프로그램이 켜져 있을 때 다시 실행하면 새로 켜지지 않고 켜져 있는 창이 앞으로 나와요.
- 작업표시줄의 캘린더 분리창도 프로그램 아이콘으로 보여요. 스탠딩 캘린더는 작업표시줄에 나오지 않아요.

**스탠딩 캘린더**
- 오래 켜 두면 바탕화면의 스탠딩 버튼이 눌리지 않던 문제를 고쳤어요.
- 스탠딩을 풀거나 끝낸 뒤 바탕화면에 캘린더 그림이 남던 문제를 고쳤어요. 탐색기가 다시 시작돼도 프로그램이 꺼지지 않고 캘린더가 다시 서요.
- Windows 11 24H2에서 Win+D를 누르면 캘린더가 바로 다시 보여요.
- 설정 › 캘린더 › ‘스탠딩 상태에서 기능 활성화하기’(기본 끔): 켜면 바탕화면의 캘린더에서 + 새 메모, 날짜 끌어 기간 일정, 스티커 끌어 놓아 일정, 메모 막대 클릭·우클릭을 쓸 수 있어요. 기능마다 체크로 고를 수 있어요. 켜면 캘린더 자리의 바탕화면 아이콘은 가려져요.

**캘린더 · 일정**
- 메모를 캘린더로 끌어 일정으로 등록할 때 꺼내지 않은 ‘매일 오늘 메모’ 스티커가 바탕화면에 나타나던 문제를 고쳤어요.
- ‘이날까지 할일’ 스티커를 캘린더 분리창 오른쪽 일정 목록에 끌어 놓아도 이날까지 할일이 풀리지 않아요.

**입력 · 붙여넣기**
- ㅁ+한자로 기호를 고르거나 글자를 한자로 바꿀 때, Enter로 고르면 줄바꿈까지 들어가던 문제를 고쳤어요. 후보창에서 Esc를 눌러도 글상자에서 빠지지 않아요.
- 한자·기호 후보창이 글상자 아래가 아니라 커서 바로 아래에 떠요.
- 엑셀 표가 가끔 표가 아니라 글자로 붙던 문제를 고쳤어요(한글을 치다 바로 붙여 넣을 때). 글·표·글이 섞인 내용은 순서대로 붙어요.
- 설정 › 일반 › ‘표 붙여넣기’: 표(기본) / 텍스트(탭 구분)를 고를 수 있어요.
- 클립보드 모아보기에 같은 내용이 두 번씩 쌓이던 문제를 고쳤어요. 같은 내용을 다시 복사하면 그 항목이 맨 위로 올라와요. 수집은 기본으로 켜져요(업데이트 후 한 번 켜짐).

**스티커**
- 끌어 옮긴 메모를 닫았다가 다시 열면 옮겨 둔 자리에 떠요. 프로그램을 다시 켠 뒤에도 같아요. ‘새 메모 오른쪽 정렬’ 자리로 돌아가지 않아요.

**화면 그리기**
- 창을 다시 보이거나 모니터를 연결·해제·절전 해제한 뒤 스티커나 창이 하얗게 남던 문제를 고쳤어요.
- 튜토리얼 설명창이 모니터가 여러 대일 때 한 모니터 안, 그 모니터 배율로 놓여요.
- 왼쪽 메뉴의 폭을 끄는 중 다른 창이 앞으로 오면 메뉴가 접힌 채 저장되던 문제를 고쳤어요.
- 실행할 때마다 그래픽 드라이버 정보를 `logs\gl.log`에 한 줄 남겨요.

**저장**
- 예전 저장 파일(`data.json`, `data.before-db.json`)은 새 저장소(`data.db`)로 옮겨진 것을 다시 읽어 확인한 뒤 지워요. `backups` 폴더는 그대로 둬요.

**확인 못 한 것**
- Windows 11 24H2 실제 PC의 자동 실행·Win+D·스탠딩 버튼, Windows 10·11 23H2의 스탠딩 잔상.
- 모니터 여러 대·배율이 다른 모니터, Intel 전용·그래픽 카드 없는 PC의 흰 창.
- 실제 엑셀 표 복사, 실제 한글 키보드의 한자 키(합성 키 입력으로만 시험).

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
