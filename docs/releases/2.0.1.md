# OhMemoJang 2.0.1

Windows 10/11 x64용 정식 릴리즈입니다. 2.0.0을 실제 화면에서 하나씩 확인하며 찾은 문제를 고쳤고, 사용법에 새 기능 안내를 더했어요.

**고친 점**
- 글자에 색을 칠한 뒤 다른 글자를 굵게 하면 그 글자까지 같은 색이 되던 문제를 고쳤어요. 이제 선택한 글자에서 고른 서식 하나만 바뀌어요.
- 굵게 · 기울임 · 밑줄 · 취소선: 선택한 글자가 전부 그 서식이면 풀고, 아니면 입혀요.
- 글자 색 팝업이 좁아 회색이 다음 줄로 넘어가던 것을 고쳤어요.
- 알람 창에 반복 · 미리 알림 · 추가 알람이 들어가며 아래 버튼이 잘리던 것을 고쳤어요(창을 키우고 스크롤을 넣었어요).
- 검색 결과의 ‘날짜 · 달력에서 보기’ 줄이 위 줄과 겹치던 것을 고쳤어요.

**사용법**
- 나만의 위키 › 사용법에 ‘⑮ 2.0 새 기능 한눈에 보기’ 페이지를 더했어요. 반복 · 미리 · 여러 알람, 글자 색 · 형광펜, 본문 우클릭, 체크박스 진행률, 여러 날 일정, 음력, 내 휴일, Ctrl+Alt+F 검색, 자동 백업을 쓰는 법을 모았어요.
- 업데이트 후 처음 켜면 사용법 페이지가 새 내용으로 바뀌어요. 사용법 탭에 직접 넣은 메모는 그대로 남아요.

**실제 화면에서 확인한 것**
음력 표시, 날짜 끌어 여러 날 일정, 툴바 끌어 일정, 본문 우클릭 메뉴, Ctrl+Alt+F 검색, 내 휴일 · 성탄절 빨간 날, ‘지원 안 됨’ 표시, 글자 색 저장, 추가 알람 · 미리 알림 · 매일 반복 알람의 Windows 알림과 확인 처리. ‘5분 뒤’는 실제 화면에서 확인하지 못했어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
