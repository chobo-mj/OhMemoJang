# OhMemoJang 0.6.4

Windows 10/11 x64용 정식 릴리즈입니다. 이번 버전은 성능 개선이 중심입니다.

- 창이 그리던 화면과 같으면 다시 그리거나 화면 전환(swap)을 하지 않습니다. 이 PC에서 창 크기를 끌 때 프레임 수가 약 45% 늘었습니다(3초에 약 110 → 약 165).
- 아무 일도 없을 때 프로그램을 주기적으로 깨우지 않습니다. 단축키·트레이는 이벤트로, 알람·자동 잠금·저장은 해당 시각에 맞춰 깹니다. 유휴 CPU 사용량이 거의 0이 되었습니다(스티커 8개를 띄워도 동일).
- 입력 커서(캐럿)가 깜박이지 않고 항상 보입니다. 깜박일 때마다 창 전체가 다시 그려지던 것을 없앴습니다.
- 찾아 바꾸기 창이 열려 있는 동안 프레임마다 모든 메모를 훑지 않습니다. 설정 비교와 스타일 적용도 바뀔 때만 합니다.
- 릴리스 빌드를 최적화했습니다(LTO). 실행 파일이 약 0.7MB 작아졌습니다.
- 설정 › 데이터에 ‘사용하지 않는 이미지 정리’를 추가했습니다. 어떤 메모와 백업도 쓰지 않는 이미지를 `images\unused`로 옮기며 삭제하지는 않습니다. 데이터 폴더를 바꾼 직후 읽지 못한 그림이 앱을 다시 켤 때까지 비어 보이던 문제도 고쳤습니다.
- 수정: 개발용 자동 테스트가 실제 `settings.txt`의 데이터 폴더를 임시 폴더로 바꾸던 문제(배포본에는 영향 없음).

자동 테스트 272개가 통과했습니다. 창 크기 조절 중의 CPU 사용은 그래픽 드라이버 대기 때문에 겸용 그래픽 PC에서는 여전히 높을 수 있습니다. 같은 화면 건너뛰기는 이 PC에서만 확인했습니다.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
