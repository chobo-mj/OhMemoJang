# OhMemoJang 2.5.0

다른 프로그램에서 글을 쓰다가 **Alt+V**를 누르면 최근에 복사한 내용을 골라 바로 붙여 넣는 **클립보이**가 생겼습니다. 설정의 단축키는 이제 원하는 키를 직접 눌러서 바꿉니다.

- **클립보이(Alt+V)**: 클립보드 히스토리에 모인 최근 100개를 커서 옆에 Windows 클립보드 창(Win+V)과 같은 크기로 띄웁니다. 이미지와 표는 썸네일로, 텍스트와 링크는 내용으로 보여 줍니다.
  - 썸네일이나 내용을 누르면 지금 커서 자리에 바로 붙여 넣습니다. ‘복사’는 클립보드에만 담고 기록을 새로 쌓지 않습니다.
  - 항목마다 압정(맨 위 고정)과 × (삭제)가 있으며, 클립보드 히스토리와 같은 기록을 씁니다.
  - 위쪽 압정을 꽂으면 다른 곳을 누르거나 타자를 쳐도 닫히지 않습니다. 압정을 빼 두면 바깥을 누르거나 키를 누를 때 닫힙니다. Alt+V를 한 번 더 누르면 닫힙니다.
  - ‘전체비우기’는 압정을 꽂은 항목과 코멘트를 단 항목만 남기고 지웁니다.
  - 색은 메인 테마를 따르고, 모니터 배율이 달라도 같은 모양으로 보입니다.
  - 클립보드 히스토리의 ‘수집 끄기’ 옆 버튼으로 켜고 끕니다(처음에는 켜져 있음). 끄면 Alt+V를 다른 프로그램이 쓸 수 있습니다.
- **단축키 설정**: 설정 › 단축키의 칸을 누르고 원하는 키를 함께 누르면 바뀝니다. 전역 단축키 네 개(빠른 메모, 캘린더 분리창, 새 스티커 메모, 클립보이)와 메모 서식·프로그램 사용 중 단축키를 모두 바꿀 수 있습니다.
  - Windows가 쓰는 키(Alt+Tab, Win+V 등), 다른 프로그램이 이미 등록한 키, 다른 동작에 쓰는 키는 이유를 알려 주고 받지 않습니다. 다른 키를 누르거나 ‘취소’(또는 Esc)를 누르면 됩니다.
  - 전역 단축키는 하나씩 따로 등록합니다. 하나가 다른 프로그램과 겹쳐도 나머지는 그대로 동작합니다.
  - ‘항상 위에’ 단축키를 실제 동작 키인 Ctrl+Shift+T로 표시합니다(이전 설정 화면에는 Ctrl+T로 적혀 있었습니다).
- **튜토리얼**: 클립보드 히스토리 다음에 클립보이 단계를 넣었습니다. 연습 스티커에 Alt+V로 연습 문장을 붙여 넣어 볼 수 있습니다.
- 나만의 위키 › 사용법에 클립보이와 단축키 변경 방법을 추가했습니다.

관리자 권한으로 실행한 프로그램에는 Windows 보안 정책상 클립보이가 붙여 넣지 못할 수 있습니다. 그럴 때는 ‘복사’를 누른 뒤 Ctrl+V를 누르세요.

Windows 10/11 x64용입니다. 설치하려면 **Setup.exe**, 압축을 풀어 실행하려면 **Portable.zip**을 받으세요. 두 파일의 SHA-256 값은 **SHA256SUMS.txt**에서 확인할 수 있습니다.
