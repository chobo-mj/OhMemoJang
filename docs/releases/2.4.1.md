# OhMemoJang 2.4.1

라이트 1에서 선보인 메인창 배치를 라이트 2·3과 다크 모드 1·2에도 적용했습니다. 테마를 바꿔도 자주 쓰는 메뉴와 버튼을 같은 자리에서 찾을 수 있습니다.

- **오늘의 할일 · 다음에 할일**에서는 프로젝트와 새 일정 아래에 보기 필터를 배치하고, 날짜별 건수와 오른쪽 메모 미리보기를 표시합니다.
- **전체메모 · 편의기능 · 설정**은 상단 색인 탭으로 전환합니다. **나만의 위키**는 탭 아래에 새 폴더 버튼과 분류 안내를 둡니다.
- **클립보드 히스토리**는 검색창과 종류 필터가 창 폭에 맞춰 줄을 바꾸고, 각 기록 왼쪽에 콘텐츠 종류나 썸네일을 표시합니다.
- 테마별 색상, 원본 배너, 기본 테마인 라이트 2와 기존 테마 선택값을 유지합니다.

Windows 10/11 x64용입니다. 설치하려면 **Setup.exe**, 압축을 풀어 실행하려면 **Portable.zip**을 받으세요. 두 파일의 SHA-256 값은 **SHA256SUMS.txt**에서 확인할 수 있습니다.
