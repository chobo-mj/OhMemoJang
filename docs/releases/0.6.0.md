# OhMemoJang 0.6.0

Windows 10/11 x64용 정식 릴리즈입니다.

- 왼쪽 메뉴 너비 조절 및 좁은 폭에서 아이콘 전용 표시.
- 캘린더·분리 캘린더·선택일 목록 드래그 개선. Shift 드래그로 이날까지 업무 지정, 선택 팝업 옵션 추가.
- 이날까지 업무의 깃발·D-day 표시, 자동 스티커 표시, 일정 설정 체크박스 및 매년 반복 추가.
- 선택일 일정 시간순 정렬과 마감 업무 목록, 일정 밖으로 빼내기 지원.
- 완료 스티커 자동 닫기 및 기존 위치 순서를 유지하는 오른쪽 재정렬 옵션.
- 관계 설정 연결 방식과 화살표 위치·크기 개선.
- 메모창 크기·글꼴 설정과 본문 서식 단축키 안내 정리. Ctrl+P, Esc 두 번, Ctrl+F, Ctrl+H 유지.
- 클립보드 자체 복사 제외 기본 ON, 개수 제한 기본 OFF. 매일 정오 정리 및 다음 실행 시 누락 정리 지원.
- 큰 이미지의 원래 배율 표시와 가로 스크롤 지원. 좁은 스티커의 이미지 메뉴 잘림 수정.
- 빠른 스티커 드래그 누락 및 겹친 캘린더의 잘못된 날짜 선택 수정.

자동 테스트 233개와 Windows 실제 클립보드 별도 테스트가 통과했습니다. 격리된 실제 창에서 메뉴 조절, 메인·분리 캘린더 드롭, 일정 편집, 스티커 완료·재정렬, 이미지 배율을 검증했습니다. Shift 조합은 입력 이벤트 테스트로 검증했으며 실제 키를 누른 드래그와 다중 모니터/DPI 조합은 직접 검증하지 않았습니다. 종료 지연 추적은 보류했습니다.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
