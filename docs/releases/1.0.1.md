# OhMemoJang 1.0.1

Windows 10/11 x64용 정식 릴리즈입니다.

- 메모에 이모지를 입력할 수 있어요. Windows 이모지 창(Win+.)으로 고른 이모지가 사라지던 문제를 고쳤어요. 프로그램이 쓰는 창 처리 라이브러리(winit)를 조금 고쳐서 넣었어요.
- 이모지 뒤에 붙는 눈에 안 보이는 문자(❤ 뒤의 모양 선택 문자, 피부색 등)가 네모(□)로 보이던 문제를 고쳤어요.
- 한계:
  - 화면의 이모지는 검은색 한 가지 색으로 보여요.
  - 아주 최신 이모지는 □로 보일 수 있어요.
  - 피부색은 화면에서는 기본 모양으로 보이지만, 메모에는 그대로 저장돼서 다른 프로그램에 붙여 넣으면 원래 모양으로 나와요.

자동 테스트 282개가 통과했어요. Win+. 이모지 입력과 한글 입력은 이 PC에서 직접 확인했어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
