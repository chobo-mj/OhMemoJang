# OhMemoJang 2.0.2

Windows 10/11 x64용 정식 릴리즈입니다. 스티커 메모와 스탠딩 캘린더를 쓰면서 찾은 문제를 고쳤고, 마우스를 움직일 때 화면이 끊기던 원인을 찾아 줄였어요.

**마우스 끊김 · 다시 그리기**
- 프로그램이 켜져 있으면 바탕화면에서 마우스가 한 번씩 끊기던 문제를 줄였어요.
  - 3초마다 모든 창을 한꺼번에 다시 그리지 않아요.
  - 스탠딩 캘린더는 내용이 바뀔 때만 그려요.
  - 마우스 이동 한 번에 여러 번 그리던 것을 한 번으로 줄였어요.
- 스티커 툴바 위를 지나갈 때 아이콘마다 툴팁이 떴다 사라지며 끊기던 문제를 고쳤어요. 툴팁은 한 아이콘 위에 잠시 멈춰야 떠요.
- 버튼을 누르지 않고 지나가기만 할 때는 화면을 덜 자주 그려요.

**스티커 메모**
- 상단 툴바에서 알람 · 메모 편집 창 아이콘을 뺐어요. 두 기능은 … 더보기 메뉴에 있어요.
- 상단 툴바의 더보기~닫기 버튼이 오른쪽 끝에 붙어요.
- 가로폭을 290px까지 줄일 수 있어요. 이 폭에서도 상·하단 툴바가 모두 보여요.
- 제목 한 줄로 접으면 완료 동그라미가 왼쪽 끝에 와요. 상세 편집 버튼은 빠졌어요.
- 제목 한 줄의 너비는 설정 › 메모창 › ‘1단 접기 크기 조절하기’에서 창을 늘이고 줄여 정해요.
- 하단 툴바의 글꼴 · 글자 크기 · 글자 색 · 투명도 팝업에 마우스를 올리면 깜빡이던 문제를 고쳤어요. 투명도 팝업이 잘리던 것, 글꼴 목록이 3개만 보이던 것도 고쳤어요.
- 메모 색상의 ‘+’(기타 색상)를 누르면 컬러판이 메뉴 안에 펼쳐져요. 예전에는 컬러판을 누르면 닫혀 버렸어요.
- 메뉴 · 팝업이 별도 창으로 떠서 작은 스티커나 분리창 밖으로도 나와요.
- 스티커 본문 우클릭 메뉴에서 휴지통 · 영구삭제를 할 수 있어요.

**스탠딩 캘린더 · 캘린더**
- 스탠딩 캘린더가 다시 바탕화면 아이콘 아래에 고정돼요(최신 Windows 11 바탕화면 구조 대응).
- 바탕화면에서 해제 버튼을 누르면 다시 고정되어 버리던 문제를 고쳤어요.
- 스탠딩 캘린더 위에 스티커를 끌어 놓아도 일정이 되지 않아요.
- 일정이 있는 스티커를 바탕화면에서 옮길 때, 최소화되거나 가려진 캘린더가 날짜를 바꾸던 문제를 고쳤어요. 이제 실제로 보이는 캘린더에 놓을 때만 일정이 바뀌어요.
- 캘린더 일정 막대의 양끝을 끌어 기간을 바꿔요. 끝을 끌 때 메모 전체가 옮겨지던 문제도 고쳤어요.
- 빈 일정 메모를 지운 뒤 캘린더에 ‘삭제된 메모’가 남던 문제를 고쳤어요. 캘린더에서 끌어 만든 메모를 빈 채로 닫으면 지워져요.
- ‘지원 안 됨’ 표시는 Windows 11 24H2에서만 보여요.

**그 밖에**
- 검색은 Ctrl+F예요. 메인 창 어디서나 검색창으로 가요. 전역 단축키 Ctrl+Alt+F는 없앴어요.
- 표 · 이미지 · 링크 모아보기에서 압정으로 맨 위에 고정해요. 링크에는 코멘트를 달 수 있고, 즐겨찾기 목록이 저장돼요.
- 클립보드 히스토리에 코멘트 · 압정이 생겼어요.
- 설정을 연 뒤 같은 메뉴를 누르면 설정이 닫혀요.
- 사용법 페이지를 새 내용으로 고쳤어요. 업데이트 후 처음 켜면 바뀌어요.

**확인 못 한 것**
- Windows 11 24H2 PC에서의 스탠딩 캘린더 대체 동작.
- 마우스 끊김이 줄어든 정도는 PC마다 다를 수 있어요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
