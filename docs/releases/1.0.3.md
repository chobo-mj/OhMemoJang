# OhMemoJang 1.0.3

Windows 10/11 x64용 정식 릴리즈입니다.

- 튜토리얼 첫 화면에 알림 안내를 넣었어요: 메모 알람은 Windows 알림으로 알려 드려요. Windows는 시작 메뉴 바로가기가 있는 앱의 알림만 보여 줘서, OhMemoJang이 시작 메뉴에 바로가기를 만들어 둬요.
- 프로그램을 제거하면 알림에 쓰던 아이콘 그림 파일과 비어 있는 폴더(시작 메뉴 폴더 포함)도 지워요. 메모 데이터와 클립보드 기록은 남겨 둬요.

자동 테스트 288개가 통과했어요. 이 PC에서 확인한 것:
- 직접 만든 시험 설치 파일로 설치·제거를 해 봤어요.
- 튜토리얼 첫 화면에 안내가 보여요.

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
