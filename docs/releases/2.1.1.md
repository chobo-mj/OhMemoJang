# OhMemoJang 2.1.1

Windows 10/11 x64용 정식 릴리즈입니다. 스티커 우클릭 메뉴와 글꼴 창, 접힌 메모 자석 정렬, 새 메모 색 번갈아 쓰기, 파란 금요일을 더했고, 튜토리얼에 캘린더 분리창 끌기와 클립보드 히스토리를 넣었어요.

**스티커**
- 제목 칸을 우클릭해도 메뉴가 나와요.
- 메뉴의 ‘닫기 버튼 잠금’: 켜면 X·Esc 두 번·Alt+F4로 닫히지 않고, 메뉴의 ‘이 스티커 닫기’로만 닫혀요. 메모마다 따로 저장돼요.
- 우클릭 ‘글꼴…’: 글꼴·크기·굵게·기울임·밑줄·취소선·글자색·형광펜을 고르고 미리보기로 본 뒤 적용해요. 바꾼 것만 적용돼요.
- 투명도는 본문·제목·상단 툴바 우클릭 메뉴에서 바꿔요. 스티커 아래쪽의 서식 줄(글자 크기·서식·색·투명도)은 없앴어요. 탭 줄은 그대로예요.
- 메뉴 창의 체크박스 네모가 보이지 않던 문제를 고쳤어요.

**접기**
- 설정 › 메모창 › 접기 › ‘컬러박스 생략’(기본 끔): 켜면 제목줄까지만 접혀요. ‘접기 1단계 건너뛰기’와 함께 켤 수 없어요.
- ‘컬러박스 크기 조절하기’: 창에서 상자 모서리를 끌어 크기를 정하고, 닫으면 적용돼요.
- 접힌 제목줄·컬러박스를 다른 접힌 메모 가까이 끌면 경계끼리 자석처럼 붙어요(기본 12pt). 설정에서 끄거나 거리를 바꿀 수 있어요.

**색 · 달력**
- 설정 › 메모창 › 새 메모 기본 색 › ‘번갈아가며’: 새 메모마다 팔레트 색이 차례로 바뀌어요. 프로그램을 다시 켜도 이어져요.
- 밝은 회색·흰 메모의 캘린더 막대에 진한 테두리가 보여요.
- 매달 21일이 있는 주의 금요일을 파란색으로 표시해요. 21일이 주말이면 그 직전 금요일, 그 금요일이 공휴일이면 그 전 주 금요일이에요.
- 월 보기 위아래의 지난달·다음 달 날짜에서도 + 새 메모, 끌어서 기간 일정, 스티커 끌어 놓기를 할 수 있고, 그 일정 막대도 보여요.

**메인 창**
- 설정 › 메모창 › ‘메인 창을 누르면 메모를 앞으로’(기본 켬): 메인 창 안을 누르면 뒤에 가려진 스티커·접힌 메모가 메인 창 앞으로 와요. 작업표시줄에서 메인 창을 고르면 메인 창이 앞으로 와요. 캘린더 분리창은 해당하지 않아요.

**튜토리얼**
- 15단계에서 19단계로 늘었어요. ‘클립보드 히스토리’, ‘분리창에 끌어다 놓기’, ‘분리창에서 Shift + 끌어다 놓기’(이날까지 할일), ‘날짜를 끌어 일정 추가하기’를 더했어요.
- 분리창 단계에서는 연습 스티커 둘이 분리창 옆에 놓이고, 스탠딩 캘린더는 잠시 창으로 풀려요.

**확인 못 한 것**
- 글꼴 창의 다크 테마 모양, 배율이 다른 모니터에서의 자석 정렬, 멀티 모니터의 튜토리얼 설명창.
- 스티커를 많이 꺼내 둔 채 오래 쓸 때의 메모리(가만히 있을 때 CPU 사용과 메모리 증가는 없음을 확인).

- **Setup.exe**: 현재 사용자에게 설치하는 설치 파일입니다.
- **Portable.zip**: 압축을 푼 뒤 `OhMemoJang.exe`를 실행합니다.
- **SHA256SUMS.txt**: 설치 파일과 ZIP의 체크섬입니다.

사용자 메모 데이터는 프로그램 제거 후에도 유지됩니다. 설치 파일은 코드 서명되지 않았습니다.
