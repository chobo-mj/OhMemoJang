# OhMemoJang 2.2.0

Windows 10/11 x64용 릴리즈입니다.

- **스티커 본문 선택 팝업** — 마우스로 드래그해 놓거나 Shift+방향키로 글을 선택하면 잘라내기, 복사, 글자색, 형광펜이 표시됩니다. 팝업은 선택 영역과 툴바를 피할 공간을 찾고, 필요하면 스티커 창 밖에 표시됩니다. 포인터가 같은 버튼 안에서 움직일 때는 그 움직임으로 새 프레임을 요청하지 않습니다.
- **서식 실행 취소** — Ctrl+Z로 본문을 유지한 채 글자색과 형광펜을 각각 되돌릴 수 있습니다. 다시 실행하면 서식이 복구됩니다.
- **스티커 경계와 창 그림자** — 펼친 스티커와 두 접기 상태의 가장자리 안쪽에 얕은 음영을 넣어 같은 색의 메모가 겹쳤을 때 구분하기 쉽게 했습니다. 스티커와 메인 창의 Windows 바깥쪽 그림자는 제거했습니다.
- **다크 모드 2** — 설정에서 기존 다크 모드 1과 그보다 조금 밝은 다크 모드 2를 고를 수 있습니다.
- **캘린더 일정 이동** — 일반·분리·스탠딩 캘린더에서 일정을 날짜 사이로 끌면 컬러바가 잡은 위치를 유지하며 포인터를 따라옵니다. 마우스를 놓을 때 날짜가 반영됩니다.

설치 파일은 현재 사용자에게 설치합니다. 포터블 ZIP은 압축을 푼 뒤 OhMemoJang.exe를 실행하면 됩니다. 두 파일의 SHA-256은 SHA256SUMS.txt에서 확인할 수 있습니다.

## 수동 확인

- 본문에서 마우스와 키보드로 각각 선택해 팝업 위치와 네 가지 동작을 확인하세요. 글자색과 형광펜을 차례로 적용한 뒤 Ctrl+Z와 다시 실행을 두 번씩 눌러 본문을 유지한 채 서식만 바뀌는지 확인하세요.
- 같은 색의 스티커를 겹쳐 펼친 상태와 두 접기 상태에서 경계가 보이는지 확인하세요. 메인 창은 최대화를 푼 상태에서 외곽 그림자를 확인하세요.
- 다크 모드 2를 고른 뒤 앱을 재실행해 선택이 유지되는지 확인하세요.
- 일반·분리·스탠딩 캘린더에서 여러 날 일정의 중간을 잡아 다른 날짜로 옮겨 컬러바의 움직임과 일정 기간을 확인하세요.
