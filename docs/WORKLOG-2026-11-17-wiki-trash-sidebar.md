# 위키 탭·폴더 휴지통 묶음과 사이드바 개선

## 요청
1. 나만의 위키 탭을 삭제하면 탭 안의 메모까지 휴지통으로 보내고, 휴지통에 `탭이름/` 한 줄로 표시한다.
   누르면 폴더처럼 열려 메모 목록이 보이고, 우클릭 ‘복구’ 또는 왼쪽 복원 버튼으로 탭과 메모 전체를
   복구한다. 탭 안 메모 하나만 복구하면 탭이 다시 생기고 그 메모만 돌아온다.
2. 위키 탭 안 메모 하나만 지우면 `탭이름/메모제목`으로 표시하고, 나중에 탭을 지우면 `탭이름/` 하나로 합친다.
   탭 안 폴더 구조도 같은 규칙.
3. 전체메모 → 폴더보기에서 폴더 우클릭에 ‘폴더 삭제 · 메모 삭제’를 추가한다. 폴더와 하위 폴더·메모가
   `폴더/` 묶음으로 휴지통에 간다.
4. 사이드바: 접기 버튼을 ‘빠른 메모’ 줄 오른쪽 끝으로, 상단 배너를 크게, 아이콘만 보이는 좁은 상태에서는
   아이콘을 크게. 좁은 상태에서 사라지던 프로젝트 영역은 ▶ 아이콘 + 선택 팝업으로 표시.

## 구현
### 휴지통 묶음 (`src/trash_groups.rs`, 새 파일)
저장 형식은 바꾸지 않았다. 묶음은 이미 저장되는 값에서 그때그때 만든다.
- 위키 묶음 = `deleted_wiki_tabs`에 든 탭 + 그 탭에 속한 휴지통의 메모(탭 아래 폴더의 메모 포함).
- 폴더 묶음 = 삭제된 전체메모 폴더(삭제된 가지의 맨 위) + 그 가지에 분류된 휴지통의 메모.
  하위 폴더의 메모는 `하위/메모제목`으로 보인다.
- 탭을 지우기 전에 따로 지운 메모는 같은 조건을 만족하므로 자동으로 한 묶음에 합쳐진다.
- 탭이 남아 있는 채 휴지통에 있는 위키 메모는 `탭이름/메모제목`으로 보인다.
- `restore_note`가 메모가 속한 탭·폴더(상위 폴더 포함)를 되살린다. 그래서 메모 하나만 복구해도
  보이지 않는 곳에 복구되는 일이 없다. 나머지 메모는 휴지통에 남는다.
- `restore_group`은 탭/폴더 가지와 모든 메모를 복구한다.
- 위키 탭 삭제(`confirm_wiki_tab_delete`)가 `trash_wiki_tab`을 부르고, 삭제 확인 문구도 바꿨다.
- 폴더 우클릭 메뉴에 ‘폴더 삭제 · 메모 삭제’ 추가(`trash_catalog_folder_with_notes`). 기존
  ‘폴더 삭제 · 메모 유지’는 그대로다.

### 휴지통 화면 (`src/catalog.rs`)
- `TableRow::Group`/`Child` 추가. 묶음 줄은 ▸/▾ `이름/`, ‘메모 N개’, 왼쪽 복원 버튼, 우클릭 ‘복구’.
  누르면 펼쳐지고 아래에 메모 줄이 들어간다. 일반 휴지통 줄에도 우클릭 ‘복구’를 넣었다.

### 사이드바 (`src/main.rs`, `src/icons.rs`)
- 접기 버튼을 ‘빠른 메모’ 줄 오른쪽 끝으로 옮겼고, 배너는 사이드바 너비 전체로 키웠다.
- 아이콘만 보이는 상태의 아이콘을 28 → 38px로 키웠다(`icon_button_sized`, `toggle_icon_sized`).
- 좁은 상태에는 ▶ 버튼을 넣었다. 누르면 프로젝트 선택 팝업과 ‘프로젝트 관리’가 나온다.
  프로젝트가 선택돼 있으면 ▶가 진하게 보인다.

## 검증
- `cargo fmt`, `cargo clippy --release --all-targets -- -D warnings`, `cargo test --release` 통과(264개).
- 새 테스트(`trash_groups::tests`) 8개: 탭 삭제 시 탭·메모 이동, 묶음 복구, 메모 하나 복구 시 탭 재생성,
  따로 지운 메모와의 합침, 위키 폴더 속 메모, 폴더+메모 삭제와 하위 폴더 표기, 폴더 묶음/메모 복구,
  ‘메모 유지’ 삭제는 묶음을 만들지 않음.

## 확인하지 못한 것
- 화면 모양(배너 크기, 38px 아이콘, ▶ 팝업, 휴지통 묶음 줄의 열고 닫기)은 직접 눈으로 확인하지 못했다.
  실행 후 확인이 필요하다.
- 묶음 줄에는 영구 삭제 버튼을 두지 않았다. 메모는 펼쳐서 하나씩 영구 삭제하거나, 설정의 보관 기간이
  지나면 지워진다.
- 위키 폴더 자체의 삭제 기능은 원래 없었고 이번에도 추가하지 않았다.

## 추가: 나만의 위키 우클릭 메뉴
- 위키 메모 우클릭: 새 폴더 / 새 위키 메모 / 위키 해제 / 메모 삭제. 새 폴더와 새 위키 메모는 그 메모가 있는
  폴더(없으면 탭 최상위)에 만들어진다. 위키 해제는 위키 표시와 분류(탭·폴더)를 지운다. 메모 삭제는 휴지통.
- 위키 폴더 우클릭: 새 폴더(같은 위치) / 새 하위 폴더 / 이름 바꾸기 / 폴더 삭제.
  폴더 삭제는 안의 메모와 하위 폴더를 상위 폴더(또는 탭 최상위)로 옮기고 폴더만 지운다(`delete_wiki_folder`,
  폴더 번호가 밀리는 것을 메모·폴더·열림 상태에서 보정). 테스트 2개 추가, 전체 266개 통과.
- 화면에서 직접 눌러 보지는 못했다.

## 추가: 위키 폴더 '폴더·메모 삭제', 캘린더 분리창 아이콘
- 위키 폴더 우클릭에 '폴더·메모 삭제' 추가: 폴더·하위 폴더를 지우고 안의 모든 메모를 휴지통으로 보낸다

  기존 '폴더 삭제'(메모는 상위로)는 그대로. 테스트 1개 추가(267개 통과).
- 캘린더 분리창의 가로 배치·스탠딩 아이콘을 최소화 버튼과 같은 높이(38px)로 키웠다.
