# 설정을 별도 창이 아니라 메인 창 안에서 보이게

## 요청
설정 버튼을 누르면 새 창을 띄우지 말고 메인 프로그램 안(내용 영역)에서 보이게 한다.

## 변경
- 설정이 별도 OS 창(`ui::dialog`, 뷰포트)이던 것을 없애고, 메인 창의 내용 영역(CentralPanel)에서
  페이지처럼 그린다(`src/main.rs`). 왼쪽 사이드바는 그대로 보인다. 내용은 기존 `ppt_settings` 그대로다.
- 페이지 제목은 "설정", 오른쪽 위에는 닫기(X) 아이콘이 나온다. 설정 중에는 분리 캘린더·새 스티커
  버튼은 숨긴다.
- 사이드바의 설정 버튼(넓은/좁은 모양 모두)은 토글이다. 다시 누르면 닫힌다.
- 다른 페이지를 고르면 설정이 닫힌다(`settings_from`로 페이지 변화를 감지). 설정 중에는 "캘린더 함께
  보기"의 오른쪽 캘린더 패널을 그리지 않는다.
- 스티커 메모 메뉴의 "메모창 설정"은 메인 창을 열고(트레이에 있었다면 복원) 앞으로 가져온 뒤 메모창
  탭을 보여 준다. 메인 창이 숨겨져 있어도 설정이 보이지 않는 일이 없게 했다.

## 검증
- 새 테스트 `settings_show_inside_the_main_window_and_close_when_another_page_is_chosen`: 설정이
  메인 화면 안에서 그려지고 뷰포트가 하나뿐이며, 다른 페이지로 가면 닫힌다.
- fmt, clippy(`-D warnings`), 테스트 243개 통과.
- 실제 화면은 직접 확인하지 못했다.
