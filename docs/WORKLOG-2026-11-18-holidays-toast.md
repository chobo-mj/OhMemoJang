# 공휴일 자동 계산 · Windows 알림 센터 토스트

## 공휴일 (`src/holidays.rs`, 인터넷 없이 계산)
- **양력 공휴일**: 신정, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절.
  - 노동절(5/1)과 제헌절(7/17)은 2026년부터 공휴일이다(2026년 4월 「관공서의 공휴일에 관한 규정」 개정, 대체공휴일 대상).
  - 예전 규칙도 따른다: 식목일은 2005년까지, 제헌절은 2007년까지, 한글날은 1990년까지와 2013년부터.
- **음력 공휴일**(설날 연휴, 부처님오신날, 추석 연휴): 한국 음력을 직접 계산한다.
  - 삭(새달)은 Meeus 49장, 태양 황경은 25장 공식으로 구하고, 둘 다 한국 시각(UTC+9)으로 날짜를 정한다.
  - 동지가 든 달을 11월로 두고, 다음 11월까지 13달이면 중기(태양 황경이 30°의 배수가 되는 때)가 없는 첫 달을 윤달로 한다.
- **대체공휴일**:
  - 설날·추석 연휴가 일요일이나 다른 공휴일과 겹치면 연휴 다음 첫 평일(2014년부터).
  - 어린이날(2014년부터), 삼일절·광복절·개천절·한글날(2021-08-15부터), 부처님오신날·성탄절(2023-05-04부터), 노동절·제헌절(2026년부터)이 토요일·일요일이나 다른 공휴일과 겹치면 그다음 첫 평일.
  - 두 공휴일이 평일 하루에 겹치면 잃은 하루만큼만 생긴다(2025-05-05 어린이날·부처님오신날 → 5/6 하루).
- **선거일**: 임기만료 선거를 공직선거법 규칙으로 계산한다. 국회의원은 임기만료 50일 전 이후 첫 수요일, 지방선거는 30일 전, 대통령은 70일 전이다. 그 수요일이나 앞뒤 날이 공휴일이면 다음 주 수요일로 미룬다.
- **임시공휴일과 보궐 대통령 선거일**: 2025년까지 정부가 지정한 날만 목록으로 넣었다. 앞으로 갑자기 정해지는 날은 알 수 없다.
- **표시**: 캘린더 칸에 빨간 날짜와 공휴일 이름을 보여 준다(마우스를 올리면 전체 이름). 일정 설정 창의 작은 달력에서도 빨간 날짜로 보인다. 한 해 계산은 한 번만 하고 기억해 둔다.
- **검증**(자동 테스트):
  - 2000~2030년 설날, 2015~2030년 추석·부처님오신날을 알려진 날짜와 비교했다.
  - 2012·2014·2017·2020·2023·2025·2028년 윤달을 비교했다.
  - 1950~2100년에 대해 달 길이(29·30일)와 설날·추석이 들어가는 범위가 정상인지 확인했다.
  - 2013~2027년 대체공휴일 전체와 2006~2028년 선거일을 비교했다.
- 참고 자료: 위키백과 ‘대한민국의 공휴일’, 인사혁신처·정책브리핑 보도자료(2026년 노동절·제헌절 공휴일 지정).

## Windows 알림 센터 토스트 (`src/toast.rs`)
- 알람이 Windows 알림으로 뜬다. ‘reminder’ 형식이라 누를 때까지 화면에 남는다.
  - 버튼은 열기 · 5분 뒤 · 확인이다. 누르면 프로그램에 전달되어 메모를 열거나 미루거나 끄고, 바로 저장한다.
  - 알림을 밀어서 닫으면 확인으로 처리한다. 시간이 지나 사라진 알림은 알림 센터에 남는다.
- **설정 › 알람**: ‘Windows 알림 센터로 알리기’를 추가했다(기본 켬). 끄거나 Windows가 알림을 받지 않으면 예전 프로그램 팝업을 쓴다.
- **알림 신분 등록**: Windows는 시작 메뉴 바로가기에 적힌 앱 ID가 있어야 알림을 보여 준다.
  - 그래서 프로그램이 시작할 때 `OhMemoJang.App` ID를 시작 메뉴의 `OhMemoJang\OhMemoJang.lnk`에 넣는다. 설치본은 설치 프로그램이 만든 바로가기에, 설치하지 않은 사본은 새로 만든 바로가기에 넣는다.
  - 이름과 아이콘은 `HKCU\Software\Classes\AppUserModelId\OhMemoJang.App`에 등록한다. 아이콘 그림은 `%LOCALAPPDATA%\OhMemoJang\notification_icon.png`이다.
  - 설치 프로그램도 바로가기에 같은 ID를 넣고, 제거할 때 레지스트리 키를 지운다.
  - 바로가기가 막 생긴 직후 첫 알림은 Windows가 버린다. 그래서 알람 때가 아니라 프로그램 시작 때 등록한다.

## 함께 고친 심각한 문제
- **0.6.4~1.0.1에서 아무 입력이 없으면 정해진 시각에 프로그램이 깨어나지 않았다.** 그래서 알람이 제때 울리지 않았다.
  - 원인: 성능 작업 때 숨겨 둔 1×1 호스트 창(`with_visible(false)`)이 시간 예약 다시 그리기를 받지 못했다.
  - 숨김을 되돌렸다(창은 원래대로 1×1 투명).
  - 고친 뒤 입력 없이 둔 상태에서 알람이 제시간에 뜨는 것을 확인했다.

## 확인
- 자동 테스트 288개(공휴일 5, 토스트 2 추가).
- 시험 프로필에서 확인한 것:
  - 25초 뒤 알람이 Windows 알림으로 떴다. 아이콘, 제목, 시각, 버튼 3개가 나왔다.
  - ‘5분 뒤’를 누르니 알람이 5분 뒤로 바뀌고 DB에 저장됐다.
  - 캘린더 2027년 1월에 신정, 2월에 설날 연휴(2/6~8)와 대체공휴일(2/9)이 빨간 글씨로 표시됐다.
- 확인하지 못한 것:
  - 설치본 바로가기의 ID 설정(설치 프로그램으로 설치해 보지 않음)
  - 집중 모드(방해 금지)에서의 동작
  - 프로그램이 꺼져 있을 때 알림 센터의 알림을 누르는 경우(프로그램이 켜지기만 하고 그 알람에 대한 답은 전달되지 않음)

## 추가: 알림 안내와 제거 정리
- 튜토리얼 첫 화면(환영)에 안내를 넣었다: "메모 알람은 Windows 알림으로 알려 드려요. Windows는 시작 메뉴 바로가기가 있는 앱의 알림만 보여 줘요. 그래서 OhMemoJang이 시작 메뉴에 바로가기를 만들어 둬요."
- 설치 프로그램 `[UninstallDelete]`를 추가했다. 제거할 때 다음을 지운다.
  - 알림 아이콘 그림(`%LOCALAPPDATA%\OhMemoJang\notification_icon.png`)
  - 비어 있으면 그 폴더와 시작 메뉴의 OhMemoJang 폴더
  - 메모(`%APPDATA%`)와 클립보드 기록은 남긴다.
- 확인: 로컬에 있는 Inno Setup 7로 시험 설치 파일을 만들었다. 설치하고 프로그램을 실행한 상태에서 무인 제거했다.
  - 아이콘 그림과 시작 메뉴 폴더는 지워졌다.
  - 클립보드 기록이 든 폴더와 메모 데이터는 남았다.
- CI는 Inno Setup 6을 쓴다. 이번에 쓴 문법은 6에도 있는 기본 항목이다.
