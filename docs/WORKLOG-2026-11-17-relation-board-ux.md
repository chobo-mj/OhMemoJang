# 관계 보드 UX 개선

## 변경
- 관련 메모 연결과 상위 → 하위 연결을 명시적으로 선택한다.
- 카드의 연결 버튼으로 시작 카드와 대상 카드를 고른다. 진행 중에는 시작 제목과 취소 버튼을 표시한다.
- 시작 카드 테두리를 강조하고, 선택한 카드가 있을 때만 일괄 작업을 표시한다.
- 종속 연결은 마주 보는 카드 가장자리 사이의 곡선과 작은 단방향 화살촉으로 표시한다. 일반 관련 연결은 방향 없는 선이다.
- 확대 배율을 보정하여 선과 화살촉이 과하게 커지지 않도록 한다. 화면 밖 연결선은 그리기를 생략한다.
- 기존 카드 이동, 관계 드래그, 단축키 동작을 유지한다.

## 검증
- cargo test --release: 222 통과, 12 ignored, 실패 없음.
- cargo clippy --release --all-targets -- -D warnings 통과.
- 격리된 QA 앱에서 상위 선택 → 하위 연결, 완료 안내, Esc 취소, 카드 장거리 이동, 창 최대화, 배율 축소를 수동 검증했다.
- 마지막 시작 카드 테두리 강조 변경은 정적 검사와 전체 테스트로 확인했다.

## 범위와 제한
- 다른 카드와 연결선의 교차를 모두 피하는 자동 경로 탐색은 적용하지 않았다. 가벼운 상수 비용의 연결선 계산을 사용한다.
- 실제 사용 데이터에 변경을 가하지 않았다. 종료 지연 추적은 요청대로 수행하지 않았다.
