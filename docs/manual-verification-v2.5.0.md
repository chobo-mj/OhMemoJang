# 2.5.0 검증 기록과 수동 검증 목록

## 자동 검증 (Windows 11, rustc 1.99.1, 릴리스 워크플로와 같은 명령)

- `cargo fmt --all --check` 통과
- `cargo clippy --locked --all-targets -- -D warnings` 통과
- `cargo test --locked` 통과 (새 테스트: 단축키 조합 읽기·쓰기, 가상 키 코드, Windows 예약 키 거부, 프로그램 안 단축키 교체, 녹화 줄 형식, 단축키 설정 거부·저장·취소, 클립보이 열기/닫기·전체비우기·위치 계산, 압정·코멘트 보존 삭제, 튜토리얼 클립보이 단계)
- `cargo build --release --locked` 통과

## 수동 검증이 필요한 항목

1. 실제 키보드·마우스로 위 표의 클립보이 동작(닫힘·압정·붙여넣기)과 단축키 녹화가 같게 되는지
2. 100%·125%·150% 배율, 배율이 다른 모니터 두 대에서 크기(Win+V와 같음)·배치·글자 겹침 없는지, 보조 모니터 커서 옆에 뜨는지
3. 커서 위치를 알려 주지 않는 프로그램(Chrome·Edge·VS Code·카카오톡 등)에서 마우스 옆에 뜨고 붙여넣기가 되는지
4. 표 항목을 Excel·Word에, 이미지 항목을 그림판·PowerPoint에 붙였을 때 원래 모양으로 들어가는지
5. Alt+V를 쓰는 프로그램(Office 리본 등)에서 클립보이가 우선하는 것이 괜찮은지, 필요하면 다른 키로 바꿔 보기
6. 한글 입력 상태에서 Alt+V와 붙여넣기
7. 관리자 권한으로 실행한 프로그램: 바로 붙여넣기는 막힐 수 있음(‘복사’ 후 Ctrl+V로 대체)
8. 다른 프로그램이 등록한 전역 단축키를 눌렀을 때 ‘이미 쓰고 있는 단축키’ 안내가 나오는지
9. 기존 2.4.1 데이터로 업그레이드: 전역 단축키 네 번째(Alt+V) 추가, 사용법 갱신, 진행 중이던 튜토리얼 단계
10. Windows 시작 시 트레이로 실행된 상태(메인 창 숨김)에서 Alt+V
11. 회사 보안 프로그램이 단축키 녹화용 보조 실행(`--shortcut-recorder`)이나 키보드 훅을 막지 않는지
12. 기록 100개가 찼을 때 스크롤·썸네일 표시 속도
13. 라이트 1·3, 다크 모드 2 테마의 클립보이 색
