# 사용법 최신화 · 첫 실행 튜토리얼

## 사용법(나만의 위키 › 사용법 탭)
- 내용을 최신 기능에 맞춰 14쪽으로 다시 썼다(친근하고 간결한 말투). 요청한 항목을 모두 담았다: 메모장 영역(제목·본문·툴바)과 완료 체크박스, 본문 요령(자동 들여쓰기·취소선·자동 제목·자동 프로젝트), 일정·알람·잠금, 스티커 접기·자동 정렬, 캘린더, 분리창·스탠딩 캘린더(**Windows 11 24H2에서는 스탠딩 캘린더가 동작하지 않는다는 문구** 포함), 끌어다 놓기와 Shift 끌어다 놓기, 편의기능(업무일지·휴지통), 클립보드 히스토리, 나만의 위키, 설정에서 천천히 읽어 보기.
- 글 내용은 코드에서 확인한 동작만 적었다(예: Shift로 끌면 선택창 없이 ‘이날까지 업무’, 휴지통은 편의기능의 탭, 클립보드 수집은 처음에 꺼져 있고 직접 ‘수집 시작’을 눌러야 켜짐).
- **기존 사용자도 갱신된다.** `Extra.guide_version`을 저장하고(새 저장 항목), 시작할 때 옛 버전이면 ‘①…’처럼 원 숫자로 시작하는 사용법 쪽만 지우고 새 쪽으로 바꾼다. 사용자가 그 탭에 직접 만든 메모는 그대로 두고, 사용법 탭을 지워 둔 경우엔 되살리지 않는다. 백업에서 복원할 때도 같은 갱신을 한다.
- 스크린샷은 기존 것을 그대로 썼다(지금 화면과 조금 다를 수 있다). 새 쪽(본문 요령, 일정·알람·잠금, 끌어다 놓기, 클립보드)은 그림 없이 글만 있다.

## 첫 실행 튜토리얼 (`src/tutorial.rs`)
- 처음 실행하면 ‘튜토리얼 시작 / 건너뛰기’를 묻는다. 시작하면 예시 데이터가 만들어지고, 항상 위에 있는 작은 창이 11단계를 안내한다: 메모장 영역 → 본문 요령 → 일정·알람·잠금 → 스티커 접기·정렬 → 캘린더 → 분리창·스탠딩 → 끌어다 놓기 → 업무일지·휴지통 → 클립보드 히스토리 → 나만의 위키 → 설정.
- 단계마다 ‘해 보기’ 버튼(예시 메모 열기, 해당 화면으로 이동, 분리창 열기 등)이 있고 이전·다음·건너뛰기를 쓸 수 있다. 창의 X도 건너뛰기로 본다. 클립보드 수집은 튜토리얼이 켜지 않는다.
- 예시 데이터: 연습 메모(본문·일정·정렬용), 예시 일정 4개(하루·여러 날·이날까지 업무), 완료한 메모(업무일지), 휴지통 메모, ‘연습 위키’ 탭(폴더 1개와 메모 2개). 모두 ‘튜토리얼’ 프로젝트 또는 ‘연습 위키’ 탭에 속한다. 연습하다 ‘#튜토리얼 ’로 시작해 만든 메모도 이 프로젝트에 들어간다.
- 끝나거나 건너뛰면(예시를 만든 뒤) 선택창이 뜬다: **예시 모두 지우고 깨끗하게 시작** / 예시 남겨 두기 / 튜토리얼로 돌아가기. 지우면 예시 메모를 완전히 지우고(휴지통에도 남기지 않음) 열려 있던 스티커를 닫고 프로젝트·위키 탭을 없앤다. 사용법과 내가 만든 다른 메모는 그대로다. 시작 전에 건너뛰면 아무것도 만들어지지 않는다.
- 진행 상태(`Extra.tutorial`)를 저장하므로 도중에 프로그램을 끝내도 이어진다. 설정 › 정보의 ‘튜토리얼 다시 하기’로 다시 할 수 있다. 업그레이드한 기존 사용자에게는 자동으로 뜨지 않는다.

## 같이 고친 문제
- **삭제한 위키 탭이 프로그램을 다시 켜면 되살아나던 문제**(0.6.3에서 위키 탭 삭제를 휴지통 묶음으로 만들 때 생긴 것): 삭제한 탭 목록(`deleted_wiki_tabs`)이 저장되지 않았다. 이제 저장한다. 이미 되살아난 탭은 그대로 보인다.

## 확인
- 자동 테스트 5개 추가(튜토리얼 4+저장 1) · 사용법 갱신 테스트 2개 추가.
- 새 프로필로 첫 실행해서 확인: 환영 창 → 시작 → 예시 메모 열기 → 11단계 → 마무리 창(예시 14개) → ‘모두 지우기’ 후 예시와 프로젝트가 사라지고 내 작업실이 비어 있음.
- 확인하지 못한 것: 11단계 각각의 ‘해 보기’ 버튼(1단계만 눌러 봄), ‘예시 남겨 두기’·‘돌아가기’, 스탠딩 캘린더 단계의 실제 동작, 기존 데이터에서 사용법이 갱신되는 화면.
