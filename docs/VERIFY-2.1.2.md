# 2.1.2 수동 검증

## 이번 변경

- [ ] Windows 11 24H2에서 설치본과 포터블을 각각 실행한다. 작업표시줄의 메인 창·캘린더 분리창에 앱 아이콘이 표시되는지 확인한다. 기존에 고정한 바로가기와 새로 고정한 바로가기도 확인한다.
- [ ] Windows 11 23H2에서 캘린더를 스탠딩으로 고정한다. 캘린더 단추와 메인 창에서 각각 스탠딩을 해제해 바탕화면에 잔상이 남지 않는지 확인한다. 아이콘 위·아래 고정 모드와 프로그램 종료도 확인한다.
- [ ] 설정 › 캘린더에서 스탠딩 기능을 켠 뒤 일반 일정, 여러 날 일정의 중간, 마감 일정, 반복 일정의 막대를 다른 날짜로 옮긴다. 일정 길이·마감 표시·반복 규칙이 유지되는지 확인한다. ‘일정 막대를 끌어 날짜 옮기기’만 켜고 이동을 확인한 뒤 해당 옵션을 끄고 이동이 막히는지 확인한다.
- [ ] 캘린더 분리창을 연 뒤 메인 창에서 분리 버튼을 다시 누른다. 같은 분리창이 메인 창 앞으로 오는지 확인한다. 최소화된 상태에도 반복한다.
- [ ] 내 작업실의 좌우·상하 캘린더에서 빈 날짜를 끌어 기간 일정을 만든다. 분리창을 함께 열어 둔 상태에도 반복하고, 날짜 범위 하나당 메모가 하나만 열리는지 확인한다.
- [ ] 내 작업실에서 메모 목록과 캘린더 사이 경계를 왼쪽으로 옮겨 목록을 좁힌다. 메모 선택과 다시 넓히기가 되는지 확인한다. 캘린더의 좌우·상하 보기에서 각각 확인한다.
- [ ] 나만의 위키 탭 이름을 더블클릭과 우클릭 메뉴로 각각 편집한다. 한글 조합을 마친 뒤 Enter로 편집을 끝내고, 앱을 재실행해 새 이름이 유지되는지 확인한다.
- [ ] 메인 메뉴의 프로젝트 관리에서 프로젝트 이름을 바꾼다. 연결 메모와 검색 필터에 새 이름이 보이는지 확인한다. 기존 프로젝트 이름으로 바꿔 두 프로젝트가 하나로 보이고 두 쪽 메모와 휴지통 메모가 유지되는지 확인한다.
- [ ] 스티커를 끌어 옮긴 뒤 닫고, 설정 › 메모창의 다음에 열 위치를 바꿔 네 가지 위치를 각각 확인한다. 이미 열린 스티커를 고를 때 위치가 바뀌지 않는지, 다른 배율의 모니터에서도 화면 안에 뜨는지 확인한다.
- [ ] 다른 프로그램과 스티커 여러 개를 띄운 뒤 작업표시줄·Alt+Tab·메인 창 클릭으로 메인 창을 선택한다. 일반 스티커와 접은 메모가 메인 창 뒤이면서 다른 프로그램 앞에 오는지 확인한다. 접은 메모끼리의 순서, 메모 편집창·분리 캘린더, ‘항상 위’ 스티커도 확인한다.
- [ ] ‘Win+D로 바탕화면을 볼 때 스티커 표시 유지’의 기본값이 켜짐인지 확인한다. 일반 스티커·접은 스티커·닫힌 스티커가 함께 있을 때 Win+D를 누른다. 열려 있던 스티커만 보이는지 확인한다. 다시 Win+D로 복귀하고 옵션을 끈 뒤 같은 동작을 확인한다. 가능하면 23H2와 24H2 모두에서 확인한다.

## 이전 인수인계에서 확인이 남은 항목

- [ ] 외장 그래픽 카드가 없는 PC에서 실행하고 절전 복귀·모니터 연결/해제 후 흰 창이나 흰 스티커가 남는지 확인한다. 재현되면 `%LOCALAPPDATA%\OhMemoJang\logs\gl.log`를 함께 기록한다.
- [ ] ‘이전 버전의 Microsoft IME 사용’을 켠 PC에서 스티커 제목·본문, 표 칸, 검색창에 ㅁ+한자로 기호를 넣는다. 후보창 위치와 불필요한 줄바꿈 여부를 확인한다.
- [ ] 스티커 10개 이상을 띄우고 몇 시간 사용한다. 유휴 상태의 CPU와 메모리 사용량을 작업 관리자에서 기록한다.

Windows 재시작 후 자동 시작은 이전 수동 검사에서 통과했다.
