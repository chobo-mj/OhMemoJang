# 설정 > 메모창: "새 메모" 구역, 모니터 선택, 오른쪽 정렬, 메모창으로 크기 설정

## 변경
- 설정의 메모창 탭에 "새 메모" 사각형 구역을 만들고 새 스티커 메모 크기, 메모를 항상 스티커 메모로
  열기, 새 메모 기본 색을 넣었다. 같은 구역에 아래 두 옵션을 추가했다.
  - **새 메모 띄울 모니터**: 자동 / 모니터 1…N. 자동은 지금 쓰는 창이 있는 모니터다. 모니터가 한 대면
    비활성이다. 저장된 번호의 모니터가 없어지면 자동으로 동작한다.
  - **새 메모 오른쪽 정렬하기**(기본 켜짐): 새 메모가 선택한 모니터의 오른쪽 가장자리에 위에서부터
    차례로 나타난다. 이미 열린 창과 겹치지 않는 가장 위쪽 자리를 고르고(`right_slot`), 열이 차면 왼쪽으로
    새 열을 시작한다. 닫힌 창의 빈자리는 다음 메모가 채운다. 끄면 기존처럼 가운데에서 계단식으로 뜬다.
  - 저장 위치는 설정(`SettingsRec`의 `new_monitor`, `new_right`). 예전 설정에는 오른쪽 정렬이 켜진 것으로 읽힌다.
- **메모창으로 크기 설정하기** 버튼(크기 선택줄의 "직접 설정" 옆): 스티커 색의 창이 현재 설정 크기로 뜬다.
  가장자리를 끌어 크기를 바꾸고 창을 닫으면(또는 Esc) 아래 너비·높이에 자동 입력된다(슬라이더 범위
  340~900 × 220~900로 보정, 정수로 반올림). 메모를 만들지 않는 크기 측정용 창이다.
- 이전부터 있던 문제를 함께 고쳤다: 빠른 새 스티커(`new_sticker`)가 설정의 크기를 쓰지 않고 항상
  360×360으로 열렸다. 이제 설정 크기로 열린다.
- 위 위치 규칙은 "처음 여는 창"(저장된 위치가 없는 창)에 적용된다. 이미 위치가 있는 창과 열려 있던
  창을 다시 열 때는 마지막 위치를 쓴다.

## 검증
- 새 테스트 7개: 오른쪽 가장자리 쌓기·새 열·빈자리 재사용·다른 모니터 무시, 새 스티커의 설정 크기,
  설정 저장·복원, 크기 창을 닫으면 값 입력(범위 보정 포함), 설정 화면에 새 구역과 버튼 표시.
- fmt, clippy(`-D warnings`), 테스트 250개 통과. 실행해 두었으나 화면에서 직접 눌러 보지는 못했다.
- 모니터가 둘 이상일 때의 실제 배치는 직접 확인하지 못했다(자동 테스트는 좌표 계산만 확인).
