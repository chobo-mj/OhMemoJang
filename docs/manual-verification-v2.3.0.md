# OhMemoJang 2.3.0 Windows 수동 검증

실사용 DB와 분리한 테스트 폴더에서 확인한다. 생성·수정·영구삭제 시험에는 검증용 메모만 사용한다.

| 기능 | Windows 앱에서 확인할 동작 | 결과 |
| --- | --- | --- |
| 공통 선택 | 폴더 보기와 전체 보기에서 일반 클릭, `여러 개 선택`, Ctrl/Shift 클릭, Ctrl+A, Esc. 완료 원형과 선택 사각 체크박스가 서로 영향을 주지 않음. 검색·접기·스크롤·탭 이동 후 선택 범위 확인. 검색·본문 한글 입력 및 Ctrl+A/Ctrl+Z가 목록에 전달되지 않음. | 대기 |
| 이동·정렬 | 한 그룹을 폴더로 끌기, 분류 해제, 전체 보기에서 폴더 대상 표시, 자동 펼치기·스크롤, 빠른 드래그. 수동 정렬에서 묶음 상대 순서, 필터 아래 숨겨진 행 보존, Ctrl+Z/다시 실행, 재시작 후 순서. 일정/위키/보드의 기존 단건 드래그 회귀. | 대기 |
| 프로젝트 | 미분류에서 여러 메모를 끌어 프로젝트로 배정. 프로젝트 메모 생성·편집·완료·휴지통 이동, 숨김·삭제·이름 병합 및 폴더/일정 보존. 기간 일정 일괄 완료 범위 및 취소. | 대기 |
| 휴지통 | 접힌 폴더/위키 그룹 선택과 Ctrl+A 범위, 하위 메모 중복 제거, 동일 메모의 여러 탭과 메모 복원. 단건·선택 영구삭제·비우기 확인창의 표시 개수, Enter 한 번, Esc, 닫기, Tab 포커스, Enter 길게 누르기, 재시작 후 상태. | 대기 |
| 휴지통 저장 오류 | 다른 창의 복원이나 보관 기한 만료로 확인 대상이 바뀌면 다시 확인. 테스트 DB가 일시적으로 쓰기 불가일 때 완료 알림이 보류되고 저장 재시도 뒤 완료 표시. | 대기 |
| 표 | 검색·범위 선택, 여러 표의 HTML/TSV 순서와 서식을 Excel·한글·Word에서 붙여넣어 비교. 선택한 블록 삭제 뒤 열린 원본 메모·한글 서식·나머지 콘텐츠와 탭 유지. | 대기 |
| 이미지 | 날짜 필터와 선택 범위, 선택 PNG 저장과 기존 필터 전체 저장, 이름 충돌과 부분 실패, 원본 메모 여러 개 열기. 다른 창에서 탭 이동·편집·잠금 후 이전 선택으로 다른 블록을 조작할 수 없는지 확인. | 대기 |
| 즐겨찾기 | 실제 Chrome/Edge HTML을 가져와 중첩·빈·동명 폴더와 여러 폴더에 든 같은 URL 확인. 검색 결과 이동, 검색 종료 시 접힘 복귀, 기본 브라우저 열기, 재시작 후 접힘·코멘트·고정 복원. | 대기 |
| 데이터 | 2.2.3 데이터 사본의 메모·첨부·휴지통·프로젝트 보존, 구형 평면 즐겨찾기와 고정 정보 이전, 신규 저장과 재시작, 변환 전 백업 복원. | 대기 |

복수 이미지의 클립보드 파일 목록과 여러 표의 이미지 붙여넣기는 외부 프로그램 호환성 확인 후 제공할 항목이다. 선택 이미지 일괄 PNG 저장과 여러 표의 HTML/TSV 복사는 2.3.0에서 검증한다.
