# OhMemoJang 2.3.0 Windows 수동 검증

실사용 DB와 분리한 테스트 폴더에서 확인한다. 생성·수정·영구삭제 시험에는 검증용 메모만 사용한다.

| 기능 | Windows 앱에서 확인할 동작 | 결과 |
| --- | --- | --- |
| 공통 선택 | 폴더 보기와 전체 보기에서 일반 클릭, `여러 개 선택`, Ctrl/Shift 클릭, Ctrl+A, Esc. 완료 원형과 선택 체크박스, 검색·접기·탭 이동 후 선택 범위. 검색·본문 편집 중 목록 단축키 차단. | 버튼, 선택 체크, 완료 비활성화, Ctrl+A, Esc, 탭 전환을 앱에서 확인했다. Ctrl/Shift 클릭 조합과 편집기 포커스 조합은 수동 검증 대기다. |
| 이동·정렬 | 일괄 폴더 이동·해제, 드롭 대상, 자동 펼치기·스크롤. 수동 정렬의 묶음 순서, 필터 아래 숨겨진 행, 실행 취소·다시 실행, 재시작. 캘린더·위키·보드의 기존 단건 드래그. | 폴더에 5개 드롭 후 실행 취소, 전체 보기에서 2개를 묶어 정렬한 결과와 DB 순서 저장을 확인했다. 자동 펼치기·스크롤과 기존 단건 드래그의 실제 Windows 창 조합은 수동 검증 대기다. |
| 프로젝트 | 미분류 드래그 배정, 메모 생성·수정·완료·휴지통 이동, 숨김·삭제·병합, 폴더·일정 보존 및 기간 일정 완료 범위. | 미분류 5개 일괄 배정과 같은 프로젝트에서 새 메모 생성·한글 수정·완료 표시를 앱에서 확인했다. 프로젝트 삭제와 기간 일정 확인창은 수동 검증 대기다. |
| 휴지통 | 그룹 선택, Ctrl+A 범위와 중복 제거, 본문 탭·소유 메모 함께 복원. 단건·선택·비우기의 대상 개수, Enter, Esc, Tab, 닫기, 키 반복, 재시작 상태. | 비우기 확인창에서 메모 2개와 본문 탭 2개를 확인했다. Esc 취소 후 재시작해도 4개 항목이 남았다. 영구삭제 Enter와 실제 DB 반영은 검증용 항목 삭제 승인 대기다. 그룹·본문 탭 복원과 키 반복은 자동 테스트로 검증했다. |
| 휴지통 저장 오류 | 확인 중 보관 기간 만료·복원으로 대상이 바뀐 경우 새 확인. 테스트 DB에 일시 쓰기 실패가 생긴 경우 알림 보류와 재시도. | 대상 변경을 자동 테스트로 확인했다. Windows에서 쓰기 오류를 일으키는 수동 검증은 대기다. |
| 표 | 검색·범위 선택, 여러 표의 HTML/TSV 순서와 서식을 Excel·한글·Word에서 붙여넣어 비교. 선택 표만 지우고 열린 원본의 서식·콘텐츠 보존. | 구형 표 2개 선택과 한번의 복사, Windows 클립보드의 두 표 순서를 확인했다. 대상 앱 붙여넣기와 실제 원본 삭제는 수동 검증 대기다. |
| 이미지 | 날짜 필터, 선택 PNG 저장과 필터 전체 저장, 파일명 충돌·부분 실패, 원본 여러 개 열기, 오래된 선택의 무효화. | 기존 메모에서 이미지 2개를 선택해 실제 PNG 2개를 생성했다. 외부 창에서 원본 탭 변경과 오류 조합은 수동 검증 대기다. |
| 즐겨찾기 | Chrome/Edge 형식 가져오기, 중첩·빈·동명 폴더, 동일 URL의 여러 위치, 검색 결과 경로 이동, 검색 종료와 재시작 후 접힘 복귀. | 테스트용 HTML을 실제 앱에서 가져와 중첩·같은 URL 두 위치, 전체 펼치기·접기, 한글 검색과 원본 경로 이동을 확인했다. 실제 브라우저 내보내기 파일과 링크 열기는 수동 검증 대기다. |
| 데이터 | 기존 메모 DB·JSON 사본에서 첨부와 휴지통 복구, 구형 고정 정보와 탭 ID 이전, 신규 저장 및 재시작·백업 복원. | 2.2.3 형식 검증용 JSON에서 메모·표·이미지·삭제된 탭·즐겨찾기 코멘트를 열었다. 새 버전으로 재시작한 뒤 탭 11개에 ID가 저장되고 변환 전 DB 백업이 생성된 것을 확인했다. |

복수 이미지의 클립보드 파일 목록과 여러 표의 이미지 붙여넣기는 외부 프로그램 호환성 확인 후 제공할 항목이다. 선택 이미지 일괄 PNG 저장과 여러 표의 HTML/TSV 복사는 2.3.0에서 검증한다.

## 릴리스 성능 검증

같은 Windows 환경에서 생성한 검증 메모로 Rust 릴리스 빌드의 화면 프레임 p95를 비교했다. 단위는 ms이며 새 프로젝트 보기에는 2.2.3 비교 값이 없다.

| 메모 수 | 2.2.3 폴더 | 변경 후 폴더 | 2.2.3 전체 | 변경 후 전체 | 프로젝트 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1,500 | 0.17 | 0.16 | 0.92 | 0.91 | 0.72 |
| 20,000 | 1.25 | 0.15 | 1.88 | 1.51 | 1.24 |

이 측정에는 운영 데이터의 대형 실물 첨부와 메모리 사용량, 장시간 입력, 저장장치별 쓰기 지연이 포함되지 않는다.
