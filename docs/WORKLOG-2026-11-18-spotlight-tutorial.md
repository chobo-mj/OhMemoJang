# 스포트라이트 튜토리얼 · 사용법 재작성 · 1.0.0

## 요청
텍스트 상자를 넘기는 책 같은 튜토리얼이 아니라, 설명하는 기능만 원래 색으로 남기고 나머지를 어둡게 가리는 방식을 원했다. 설명창은 그 기능을 따라다니고, 시연을 보여 주며, 직접 해 보게 한다.
핵심 기능은 다음과 같다: 제목 자동 입력, #프로젝트, 여러 단계 목록과 Enter로 위 단계 올라가기, 물결 취소선, [] 체크박스, 드래그로 일정 만들기, Shift 드래그로 이날까지 할 일 만들기, 오른쪽 제목만 정렬, 프로젝트 필터, 완료 → 업무일지, 캘린더 분리, 스탠딩.
사용법 위키와 그림도 새로 만든다.

## 구조 (`src/tutorial.rs`)
- **어두운 화면**: OpenGL을 쓰지 않는 일반 Win32 창이다. 검은색으로 칠하고 창 전체에 알파 175를 준다. 위치는 화면 전체이고 항상 위에 있으며, 포커스를 가져가지 않는다.
  - 설명하는 부분은 `SetWindowRgn`으로 구멍을 내서 원래 색으로 보이고 클릭도 그대로 된다. 어두운 곳의 클릭은 막는다.
  - 구멍 둘레에는 노란 테를 그린다.
  - egui 창으로 만들었을 때는 레이어드 GL 창이 처음 크기로만 그려지는 문제가 있어서 바꿨다.
- **위치 표시**: 각 창이 그리는 동안 `tutorial::mark(ctx, Spot, rect)`로 화면 좌표(픽셀)를 남긴다. 튜토리얼이 꺼져 있으면 아무 일도 하지 않는다.
  - 스티커 창, 메뉴/대화창(항상 밝게), 메인 캘린더 격자, 캘린더 분리창 버튼, 스탠딩 버튼, 프로젝트 필터(펼친 목록 포함), 왼쪽 프로젝트 목록, 내 작업실 목록, 편의기능 메뉴와 화면에 남긴다.
- **설명창**: 따로 뜨는 egui 창이고, 포커스를 가져가지 않아 스티커에 계속 입력할 수 있다.
  - 밝은 부분과 열린 메뉴를 가리지 않는 자리를 고른다(옆 → 위아래 → 모서리 중 가장 적게 가리는 곳).
  - 내용 높이에 맞춰 크기가 바뀐다.
  - 어두운 화면이 맨 위로 올라갔을 때만 그 위로 올라가므로, 나중에 열린 메뉴(스티커 정렬 하위 메뉴 등)가 설명창 뒤에 숨지 않는다(요청된 정렬 메뉴 문제 수정).
- **반응형**: 단계마다 실제 데이터를 보고 해냈는지 판단하고, 1.6초 칭찬 뒤 다음으로 넘어간다. 업무일지 단계는 볼 시간을 주려고 ‘다음’을 기다린다.
- **시연**: 단계마다 5초짜리 반복 애니메이션을 그린다: 타이핑, 목록, 취소선, 체크박스, 드래그, Shift 키, 정렬, 필터, 완료, 업무일지, 분리, 스탠딩.
- **상태 저장**: `Extra::tutorial`(단계)과 `tutorial_notes`(연습 메모 번호)를 저장한다. 끝나거나 건너뛰면 연습 메모와 ‘튜토리얼’ 프로젝트 메모를 지울지 묻는다.

## 사용법·그림
- `GUIDE_VERSION` 3. 본문 요령, 끌어다 놓기(달력 아이콘을 잡아야 함), 내 작업실(프로젝트 필터, 완료 → 업무일지), 정렬(툴바 우클릭)을 실제 동작에 맞게 고쳤다.
- 그림은 `src/guide_stage.rs`(손으로 돌리는 테스트)로 만든 예시 데이터로 다시 찍었다: home, sticker, lists, calendar, calwindow, allmemo, utilities, clipboard, wiki, settings. 클립보드 그림은 개인 기록이 찍히지 않게 따로 만든 빈 프로필에서 찍었다.
