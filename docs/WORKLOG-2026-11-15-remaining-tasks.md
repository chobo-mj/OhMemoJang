# 2026-11-15 남은 작업과 검증 기록

## 오늘 메모 자동 표시 점검
- 요구사항: 설정의 매일 오늘 메모 자동으로 띄우기를 켜도 일정 없는 열린 메모는 바탕화면에 유지한다.
- 코드 확인: daily_today는 지난 미완료/오늘 일정 메모를 추가로 열며, 일정 없는 기존 창을 닫지 않는다. 세션 복원도 일정 유무로 창을 제외하지 않는다.
- 회귀 테스트: daily_auto_open_keeps_undated_stickers_open. 자동 표시 및 날짜 전환 후 재실행에서 일정 없는 창의 open 상태와 날짜가 유지되는지 검사한다.
- 현재 자동 정렬은 모든 열린 메모에 적용된다. 일정 없는 창도 제목 모드와 정렬 위치로 바뀔 수 있다.

## 구현된 변경
- 열 경계 드래그, 표 Ctrl+A, 전체 크기를 보존하는 열/행 균등 분배, 표 삭제 확인.
- 셀 편집 Ctrl+Z에 편집기 기본 이력 사용, Ctrl+0 배율 복원.
- 본문/표 이력의 Ctrl+Y 및 Ctrl+Shift+Z 다시 실행.
- 본문 우클릭 잘라내기/복사/텍스트 붙여넣기.
- 항상 위 고정을 Ctrl+Shift+T로 변경. Ctrl+P, Esc 두 번, Ctrl+F, Ctrl+H 유지.
- 동일 본문 레이아웃 재사용. 텍스트, 서식, 글꼴, 색, 그림/표 크기, 너비, 화면 배율 변경 시 재계산.

- undo/redo 역이력에서 탭 전체 Snapshot을 제거했다. 본문/표/표 삽입·삭제별 역연산 데이터만 보관하여 관련 없는 그림·표 복사를 줄였다.
- 행/열 드래그가 끝나면 임시 표 스냅샷을 제거한다.
- 우클릭 붙여넣기에서 텍스트를 읽지 못할 경우 이미지 클립보드를 읽어 다음 편집 프레임에 삽입하도록 추가했다. 실제 클립보드 UI 검증은 남아 있다.
- 전체 release 테스트 218개 통과, 12개 ignored. clippy 경고 없음, fmt 및 diff 검사 통과.
- 위 수정은 자동 검증 결과다. 기존 목록의 실제 창 조작, GPU/연속 리사이즈 성능, 캐시 무효화, 실제 재시작/새벽 5시 검증은 완료 처리하지 않았다.

## 종료 지연 후속 수정
- 강제 저장(force)은 저장 주기 제한만 건너뛰며, 변경 추적이 정상일 때는 수정된 메모만 직렬화/해시하도록 변경했다. 저장 오류 후 재시도와 저장 폴더 변경은 전체 검사한다.
- 트레이 종료 요청을 프레임 시작에서 처리하여 화면/클립보드 처리 뒤로 밀리지 않게 했다.
- 종료 직전 입력이 자동 저장 주기에 도달하지 않았더라도 저장되는 회귀 테스트와 기존 저장/창 복원 테스트 통과. clippy 통과.
- 최신 release 빌드와 앱 실행 완료. 종료 속도 실측은 아직 수행하지 못했다.
- 실제 창 재검증은 computer-use의 `foreground window did not report a process id` 오류로 중단됐다. 창 목록을 다시 조회하고 새 핸들로 재시도했지만 같은 오류가 발생했다.

- 검증 메모에 A/B/C/D 2×2 표를 붙여넣었다. Ctrl+Z로 표 제거, Ctrl+Shift+Z로 내용 포함 복원 확인.
- 셀 선택 후 Ctrl+A로 전체 셀 선택 확인. 표 삭제 버튼에서 확인 메뉴가 표시되고 즉시 삭제되지 않는 것을 확인.
- 표가 있는 검증 메모 최대화 후 레이아웃 유지 확인.
- 열 드래그는 기존 수정본에서도 실패했다. 경계의 primary_pressed를 직접 처리하고 시작 너비와 절대 이동 거리로 계산하도록 재수정. 회귀 테스트와 clippy 통과, 새 실행 파일 적용 후 재검증 대기.
- 표 삭제 확인 메뉴에서 Esc를 눌러도 메뉴가 남는 현상을 관찰했다. 창 외부 영역 클릭으로는 닫혔으며 Esc 처리 경로 추가 조사가 필요하다.
- 수정 실행 파일 교체를 위해 사용자의 트레이 종료 응답 대기 중. 종료 속도는 아직 실측하지 않았다.

## 배포 준비 상태
- Esc로 표 삭제 확인 메뉴 닫힘을 실제 창에서 확인했다.
- 행 경계 드래그는 재검증에서 실패하여 한 프레임에 누름/이동이 함께 도착하는 경우 최초 press_origin으로 판정하도록 추가 보완했다. 최신 보완의 실제 창 검증은 남아 있다.
- 종료 후 잔류 프로세스가 일정 시간이 지난 뒤 사라지는 현상을 확인했다. 종료 시간 및 근본 원인 검증은 완료되지 않았다.
- 자동 테스트 219개 통과(12개 ignored), clippy 통과. 배포는 기존 정책에 맞춰 UI preview 사전 배포로 제공하며 위 제한을 공개한다.
