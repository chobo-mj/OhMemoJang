# 2026-11-15 남은 작업과 검증 기록

## 오늘 메모 자동 표시 점검
- 요구사항: 설정의 매일 오늘 메모 자동으로 띄우기를 켜도 일정 없는 열린 메모는 바탕화면에 유지한다.
- 코드 확인: daily_today는 지난 미완료/오늘 일정 메모를 추가로 열며, 일정 없는 기존 창을 닫지 않는다. 세션 복원도 일정 유무로 창을 제외하지 않는다.
- 회귀 테스트: daily_auto_open_keeps_undated_stickers_open. 자동 표시 및 날짜 전환 후 재실행에서 일정 없는 창의 open 상태와 날짜가 유지되는지 검사한다.
- 현재 자동 정렬은 모든 열린 메모에 적용된다. 일정 없는 창도 제목 모드와 정렬 위치로 바뀔 수 있다.

## 구현된 변경
- 열 경계 드래그, 표 Ctrl+A, 전체 크기를 보존하는 열/행 균등 분배, 표 삭제 확인.
- 셀 편집 Ctrl+Z에 편집기 기본 이력 사용, Ctrl+0 배율 복원.
- 본문/표 이력의 Ctrl+Y 및 Ctrl+Shift+Z 다시 실행.
- 본문 우클릭 잘라내기/복사/텍스트 붙여넣기.
- 항상 위 고정을 Ctrl+Shift+T로 변경. Ctrl+P, Esc 두 번, Ctrl+F, Ctrl+H 유지.
- 동일 본문 레이아웃 재사용. 텍스트, 서식, 글꼴, 색, 그림/표 크기, 너비, 화면 배율 변경 시 재계산.

## 남은 작업
- [ ] 실제 창에서 열 너비 드래그가 셀 선택으로 처리되는 문제 조사 및 수정. 두 차례 UI 시도에서 너비 변경이 확인되지 않았다.
- [ ] 열/행 드래그의 실행 취소·다시 실행, 병합 셀 경계, 확대 배율, 수평 스크롤 조합 검증.
- [ ] 우클릭 잘라내기/복사/붙여넣기의 실제 클립보드 처리와 선택 영역 보존 검증. 이미지 전용 클립보드는 현재 메뉴의 텍스트 읽기 실패 경로를 개선할 필요가 있다.
- [ ] 표 삽입·삭제·셀 편집·본문 편집이 섞인 다시 실행 이력과 포커스 검증. 현재 역이력은 해당 탭 스냅샷이므로 대형 표/그림이 있는 탭의 메모리 비용도 점검.
- [ ] 셀 편집 Ctrl+Z/Ctrl+Y, Ctrl+Shift+Z, Ctrl+A, Ctrl+0 및 유지한 단축키들의 실제 창 검증.
- [ ] 균등 분배와 표 삭제 확인의 실제 창 검증.
- [ ] 긴 본문/서식/표 조합의 연속 리사이즈·최대화·스크롤 성능 측정. 새 본문 캐시와 셀 레이아웃 비용을 구분하고 GPU 업로드/프레임 시간도 측정.
- [ ] 본문 캐시의 테마·배율·글꼴 변경과 창 재생성 시 무효화 검증.
- [ ] 매일 자동 표시 설정의 실제 재시작 및 새벽 5시 전환 검증.

## 확인한 결과
- 기존 전체 테스트 216개 통과, 12개 ignored. clippy 및 fmt 통과(자동 표시 회귀 테스트 추가 전).
- 기존 최대화 CPU 벤치마크에서 spacer font 사용 시 약 0.91ms. 새 캐시의 개선 수치를 뜻하지 않으며 GPU 시간은 포함하지 않는다.
- 최신 release 앱의 새 메모에서 한글 입력 → Ctrl+Z → Ctrl+Y 복원 확인.
- 본문 우클릭 메뉴 표시 확인. 실제 클립보드 처리까지 검증한 것은 아니다.
- 기존 표 메모 최대화 후 표/본문 표시 확인. 지속적인 프레임 성능은 미측정.
- UI 검증용 새 메모가 하나 남아 있다. 기존 메모의 완료 상태는 클릭 후 원래대로 복원했다.

- 자동 표시 회귀 테스트 추가 후 해당 테스트 통과, clippy --release --all-targets -- -D warnings 및 cargo fmt --check 통과.
