## 끝난 것 (푸시 안 함)
- 창 아이콘을 매 프레임 다시 풀던 문제를 고쳤다(`src/app_icon.rs`, `Arc` 공유). 18창에서 호스트 프레임이 17.5ms에서 2.9ms로 줄었다.
- 내장 GPU 선택(`SHIM_MCCOMPAT`)은 시도한 뒤 되돌렸다. Intel 드라이버에서는 어떤 창에도 내용이 그려지지 않았다.
- 매 프레임 본문 복사 두 곳을 없앴다(`consume_body_project`, `legacy_body`).
- 우클릭 메뉴: 단축키 표시, 모두 선택, 링크 열기를 넣고, 표 메뉴의 순서를 본문 메뉴와 맞췄다.
- 하단 메시지(`doc.status`)가 5초 뒤 사라진다. 이미지 복사의 성공·실패를 알린다.
- 설정 재배치: 일반에서 스티커 동작은 메모창으로, 캘린더 끌어 놓기는 캘린더로 옮겼다. 메모창은 4개 묶음이 됐다.
- 스티커 도움말 문구를 고쳤다(색상 상자는 한 번 누르면 복원).
- 손대지 않은 스티커 쉬기: 마우스만 움직이는 프레임에서 포인터와 먼 스티커는 UI를 만들지 않고 마지막 그림을 유지한다(`studio::may_rest`, vendor `eframe_rest`).
- 본문 속 주소 우클릭에 '링크 열기'·'링크 주소 복사'를 넣었다.
- 메인 창 쉬기: 포인터가 스티커 안쪽 깊이 있을 때 메인 창도 같은 방식으로 쉰다.

## 남은 것 (우선순위 순)
1. 툴바 간소화: 사용자 결정으로 보류(2026-11-19, '지금은 그대로'). 제안했던 안은 다음과 같다.
   - 표: 정렬 3개를 하나로 합치고, 표 복사는 우클릭 메뉴로 옮긴다.
   - 이미지: 크기 4개를 '크기 ▾' 하나로 합친다.
   - 스티커: 기울임·밑줄·취소선을 '서식 ▾'로 묶고, 투명도는 더보기로 옮긴다.
   다시 요청이 있을 때만 진행한다.
2. 방어 조건 추가 조사: 아래 세 가지는 점검했고 문제없다(2026-11-19).
   - 오래된 메모 인덱스: 메모는 목록에서 지워지지 않는다. 영구삭제해도 `purged`·`deleted` 표시만 남아 인덱스가 바뀌지 않는다.
   - 시간 입력: 시는 0~23, 분은 5분 단위이거나 `step_minutes`로 범위 안에서만 바뀐다. `and_hms_opt(...).unwrap()`은 안전하다.
   - 끌기 관련 `take().unwrap()`: 모두 바로 앞에서 값이 있는지 확인한다.
   다른 사례(예: 끌어 놓기 실수)는 사용자 제보가 있으면 다시 본다.
3. 성능(남은 큰 것):
   - (끝남) 손대지 않은 스티커 쉬기: `studio::may_rest` + vendor `eframe_rest`. 실제 데이터 4초 스윕 CPU가 약 373ms에서 242ms로 줄었다. 작업일지 '전역 최적화 4' 참고.
   - (끝남) 스티커 안에서 움직일 때 메인 창 쉬기: `Studio::main_quiet`. 실제 데이터 4초 스윕(스티커 위) CPU가 평균 약 474ms에서 274ms로 줄었다. 작업일지 '전역 최적화 5' 참고.
   - NVIDIA 드라이버의 창당 스레드·메모리(실제 데이터 약 1GB, 320 스레드): 창별 GL 컨텍스트나 wgpu 백엔드를 검토한다. 큰 작업이다.
4. (끝남) 표 메뉴·본문 메뉴를 화면에서 확인했다. 본문 속 주소를 우클릭하면 링크 항목이 나온다.
